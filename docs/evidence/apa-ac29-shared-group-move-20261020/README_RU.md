# APA AC29: перемещение целой нативной группы

## Новая работающая функция

`apa-native-group-move/1` принимает Group GUID, точный состав и явный горизонтальный вектор переноса в метрах. Общий selector выбирает существующий `MoveNativeGroupV1`, проверяет фактическую регистрацию и выполняет одну нативную команду через общий Router/registry `VerifiedNativeGroupMove`/SceneWriter/SQLite.

Scope включает обе Column и оба принадлежащих ColumnSegment. Перед записью проверяются полный состав плоской группы, параметры/материалы/родство, точная модель и отсутствие пересечений по нативному BREP. После записи проверяются сохранность всех GUID, точные новые координаты, неизменность относительной формы/материалов/сегментов, членство всех групп колонн и184 нетронутых физических элементов.

## Установка и контракт

Установлен код `c980c00ea8c0ca92ddc73c84af349757d18a5405` с резервными копиями. Изменены существующие функции selector/runtime/registry и общий вызывающий сценарий, добавлены точный контракт и адаптер. Все296 прежних контрактов,30 файловых и4semantic команды сохранены. APX, зависимости, исходные PLN и main не менялись. Нового исполнителя нет.

Новые необходимые автоматические проверки охватывают выбор одной нативной команды, обязательную scope сегментов, столкновение на целевых позициях, ошибочное положение, изменение сохранённой геометрии, нулевой/вертикальный/нечисловой перенос. Регрессии выполняются в CI; точные текущие статусы в `ci-checks.json`.

Границы: плоская группа2..128 полностью прочитанных Column на этаже0, горизонтальный перенос без вращения, масштабирования и смены состава; пересечение/касание целевых solid отклоняется. LIVE выполнен на двух Column. Другие типы и вложенные группы этим не объявлены принятыми.

Исторические имена общего формата/вызывающего сценария содержат GROUP_CREATE; фактические команда/авторизация/счётчики фиксируют MOVE:0созданий,0разгруппировок,1перемещение. Прежние принятые grid8×4/LINEAR/линия/оси/создание/разгруппировка не повторялись.

Доказательства: `receipt.json`, `independent-audit.json`, `deployment.json`, `ci-checks.json`, `artifact-sha256.json`. PLN/SQLite/полные дампы остаются локально. Задача реестра `APA-P70.A11.S19`.
