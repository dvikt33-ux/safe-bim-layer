# APA AC29: выбранные пересечения именованных осей — установлено и принято

## Новая работающая возможность

Пользователь задаёт ортогональные оси с обозначениями и точными координатами в метрах, затем выбирает нужные пары. APA размещает нативные копии только на этих пересечениях; сохраняет обозначения в плане и отчёте. Поддерживаются неравные расстояния между осями и разреженный выбор из большой сетки. Без списка пар работает прежняя полная сетка (до32позиций); один ряд соответствует распределению вдоль оси.

`AXIS_INTERSECTIONS.selectedIntersections` подключён к существующему mass selector, capability discovery, Router, registry и SceneWriter. Индивидуальные копии выполняются одним `MoveElements(copy=true)`. Для уже принятой группы автоматически выбирается существующий `CloneNativeGroupV1`; LIVE нового режима для групп здесь не заявлен. Геометрия/число/оси не извлекаются предположениями из текста.

## Установка и контракт

Функция установлена в действующий APA из `513f02050a70ce14e936305bbbeab9217082ceca`: заменены два Python модуля с резервными копиями и точной сверкой прежних SHA. Все296 прежних контрактов,30 файловых и4semantic команды сохранены; каталог298. APX, зависимости, main и защищённые исходники не изменялись. Новые автоматические проверки включены в Windows CI3.11/3.12, обе SUCCESS на исполнявшемся коде. Регрессии выполняются CI; принятые прежние операции повторно не исполнялись.

Границы: размещение по явным координатам ортогональных осей; это не создание нативных объектов сетки осей Archicad и не чтение неопознанных осей из модели. Неизвестные/повторные пары, неоднозначные обозначения, повторные координаты, несогласованная точка отсчёта, запрос nativeaxiscreation и выход за лимиты отклоняются до записи.

Одна LIVE-приёмка новой функции выполнена в отдельной копии принятого снимка линии `a72d5451…`; сохранены донорский снимок, прежний `f9f17200…`, принятый gridPLN `b6b44dc1…` и оригинал `3a74d7cb…`. Для следующей функции повтор этих сценариев не требуется.

Доказательства: `receipt.json`, `independent-audit.json` (точное соответствие оси→GUID/сегмент/координаты), `placement-plan.json`, `deployment.json`, `ci-checks.json`, `artifact-sha256.json`. PLN, полные дампы и SQLite остаются локально. Реестр: `APA-P70.A11.S16`.
