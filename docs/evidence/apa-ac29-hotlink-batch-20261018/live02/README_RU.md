## Сохранение и параллельная работа

Первоначальная новая рабочая PLN прошла batch CREATE, независимое native readback и GuardedSave. В 20:58:48 UTC записана исходная `saved.json` с SHA `bca84b…`; в оригинальном SQLite обе сцены PASS. Затем байты рабочей PLN изменились, её SHA стал `6c14ea7842a3d33d47d702fce5a7e3b2468f06daa6eb8f398dfc8bd445c782e8`, время записи 20:59:44 UTC. Первый `--check-closed` правильно остановился на несовпадении SHA. Пользователь подтвердил параллельную работу в Archicad; конкретная дополнительная файловая запись независимо не атрибутирована. **Поздняя изменённая PLN не объявлена принятой**, не удалялась и не откатывалась.

Её BPN оказался побайтово равен хешу исходного GuardedSave. Оба файла, исходные manifest/saved receipt и SQLite сохранены без изменений. Из BPN создан новый отдельный `hotlink-batch-live02-guarded-snapshot.pln`, SHA строго совпал с исходной квитанцией сохранения. Это копирование файлов, не новая вставка, сохранение или перезапись поздней PLN.

Для независимой проверки создано **производное состояние только для чтения**: оно явно содержит хеши исходного manifest, saved receipt и SQLite, меняет только привязку пути/порта для проверки точных сохранённых байтов и сохраняет attempted/SQLite, блокирующие повтор записи. Исходное состояние не переписывалось. Происхождение опубликовано в [persistence-provenance.json](persistence-provenance.json).

После штатного запуска отдельного AC29 через зарегистрированный Archicad Starter снимок открыт на 19727. Первое чтение подтвердило все 119 GUID, тот же BREP и байты. Затем снимок **фактически закрыт через GUI без дополнительного сохранения**, `--check-closed` получил native 4001/no open project, снимок повторно открыт с диска. Штатный `--verify-reopen` завершился PASS в 21:09:52 UTC. Дополнительный read-only аудит в 21:10:02 UTC отдельно подтвердил сохранность всех 69 исходных BREP, 48 владельцев, оба корня, нативные настройки, фактические границы, оба зазора 10 м и исходные SHA.

Вся операция использует прежние DynamicCommands → BIM Graph → SceneWriter/SQLite → Tapir. Нового APX, writer, router и нативных API-команд нет. Прежние проекты на 19723–19725 не переключались и не сохранялись; их идентичность подтверждена в конце. `main` не изменялся, PR остаётся draft.
