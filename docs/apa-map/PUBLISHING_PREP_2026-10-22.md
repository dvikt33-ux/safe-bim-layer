## Однократное действие владельца репозитория
Открыть https://github.com/dvikt33-ux/safe-bim-layer/settings/pages
В Build and deployment выбрать Source: Deploy from a branch, Branch: main, Folder: /docs, затем Save.
После успешного развёртывания проверить https://dvikt33-ux.github.io/safe-bim-layer/apa-map/ и загрузку project.json в браузере.

## Дальнейшая автоматизация
1. Обновлять project.json при изменениях исследований и решений.
2. Добавить валидатор JSON и GitHub Actions для проверки данных.
3. Не менять статусы LIVE/ACCEPTED без протокола испытаний.
4. Отмечать дату, источник, ссылку на доказательство и характер изменения.
5. Проверить на телефоне раскрытие веток, контраст статусов и поиск.

GitHub Pages публикует изменения файлов после коммита в main, когда Pages включён; извлечение новых фактов из произвольных отчётов потребует отдельной автоматизации.
