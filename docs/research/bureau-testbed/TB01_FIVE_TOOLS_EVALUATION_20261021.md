# ТБ-01 — оценка Perplexity, Firecrawl, PostHog, Playwright и Composio
Дата: 21.10.2026. Статус: **SOURCE_REVIEW / НЕ LIVE**, дополнение к draft PR #193. Тестовое бюро ещё не развёрнуто.

## 1. Вывод
Пять предложенных пользователем компонентов **не дублируют** основной контур управления и подходят для отдельного исследования. В первую волну изолированных тестов включить **Playwright MCP и Composio**, в исследовательский поток **Firecrawl и Perplexity Search API**. **PostHog** подключать после появления измеряемых реальных событий и настроенной политики сбора данных. Ни один компонент нельзя объявлять внедрённым без приёмочных доказательств.

## 3. Точное распределение в архитектуре ТБ-01
Руководитель -> ГАП (единый управляющий контур) -> дирекции/исполнители.
- Perplexity: **обнаружение потенциальных источников**; результат с URL помещается в карантин до проверки оригинала.
- Firecrawl: **сбор и нормализация** страниц/официальных руководств с сохранением исходного URL, времени загрузки, версии и контрольной суммы. Не назначает задания и не определяет истинность.
- RAGFlow (либо Dify): **поиск внутри уже собранного корпуса**, не заменяет web search и не делает официальный акт/редакцию действующими.
- Composio: **сервисные операции** (только разрешённые scopes и пользовательские подключения); первоначально read-only на тестовом пространстве GitHub/Drive, потом ограниченные записи с отдельным подтверждением.
- Playwright: **управление тестовым web-интерфейсом и независимые E2E-проверки**. Базовый вариант PR #187 использует Opera/Automa, Playwright — A/B-кандидат транспортного слоя; нельзя давать обоим доступ к одной рабочей вкладке и отправке.
- PostHog: **телеметрия** хода процесса, в том числе задержка/срыв/ошибка/расход/успех проверки, без передачи содержимого приватных сообщений.
- GitHub / Google Drive: единые исходники, отчёты, версии, квитанции и архив; управляющее состояние владеет одним сервисом. Внешние поисковые сервисы — не источники истины.

## 5. Задание исполнителям после развёртывания
- Архитектор-исследователь: сравнить Perplexity API и существующий search на идентичном корпусе, не оплачивать API без бюджета.
- Инженер данных: сравнить Firecrawl и существующие способы сбора данных по полноте/происхождению и стоимостью 100 страниц.
- Интегратор: исследовать Composio в отдельно выданном тестовом аккаунте и заявленных scopes; существующие подключённые Google Drive/GitHub уже могут решать тот же вопрос без Composio, сравнить обе возможности.
- Инженер браузерной автоматизации: сравнить Playwright MCP и Automa на **одинаковых тестовых интерфейсах**, без открытия/изменения пользовательских боевых чатов.
- Независимый аудитор: составить отрицательные тесты, проверить данные и полномочия.
- Наблюдаемость: добавить PostHog только после описания схемы телеметрии, исключения секретов и подтверждения цены/ограничений.

## 6. Необходимые стратегические решения перед LIVE
1. Где будет исполняться ГАП при отключённой Windows: облачная служба или отказ от 24/7. Подключение облачных сервисов само по себе не делает локальный Archicad доступным.
2. Что считать системой ведения задач — PR #187 или Paperclip. Нельзя оба.
3. API сначала, UI-автоматизация — только когда отсутствует надёжный официальный API.
4. Firecrawl/Perplexity и Composio — внешние сервисы: отдельно утверждать расходы и доступ к материалам, не публиковать ключи.
5. Для PostHog исключить session replay приватных ChatGPT-страниц, если нет явной и законной необходимости.
