# A02.S02 — source and edition bindings on existing project packs

The existing accelerator can now attach a reproducible normative requirement pack to its CSE/project pack and actual native junctions. It retains all selected CSE candidates and their approval state. There is no new geometric executor, compliance solver, native write or external-file import.

`compile_project_normative_pack` uses the existing semantic brief, project pack and native context. A native binding includes GUID, materials/context and actual body signature; a changed BREP invalidates the attached system evidence even when bounds are unchanged. Attachment verifies both the original project-pack digest and the normative result digest.

The six source-linked requirements cover envelope/thermal bridges, roofing technology, a specifically conditional bitumen-parapet detail, fire interfaces and window installation layers. Official registry metadata for SP50.13330.2024, SP230.1325800.2015, SP17.13330.2017, SP2.13130.2020 and GOST30971-2012 was checked on 2026-10-12. Metadata is distinct from full clause text and project compliance; see primary registry links in the catalog.

Jurisdiction is explicit and source-linked. The brief's region or a PLN filename cannot certify it. Native `SinglePlane` describes geometry rather than a roofing technology. Unknown or stale CSE evidence stays NOT_VERIFIED; only a source/body-bound known different technology excludes a system-specific rule. Research clause locators remain NOT_VERIFIED and all numeric evaluation is disabled. No loads, fire classes, thermal coefficients, parapet dimensions or regulatory engineering approval are invented.

It emits 24 bindings: 20 NOT_VERIFIED, 4 NOT_APPLICABLE (window-family rule). Its normative digest is attached to the unchanged existing pack. Missing jurisdiction, certified layer/system evidence and full clauses are explicit dependencies. Native calls during this step: zero. This is OFFLINE_PASS with cached actual native input; engineering acceptance remains ENGINEERING_NOT_VERIFIED.

18 new focused checks exercise the end-to-end pack, edition mismatch, unknown jurisdiction, family/system applicability, body/material invalidation, malformed data and digest protection.
