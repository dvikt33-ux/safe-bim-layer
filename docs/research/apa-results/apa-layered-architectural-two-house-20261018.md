## Source-only испытания PyMuPDF (локальный исследовательский контейнер, v1.26.7)

Официальные исходные PDF-пути сохраняют `layer` для каждого графического пути. Следующие количества — **PDF path**, не BIM-стены:

| PDF/страница | План | Путей несущих стен | Путей перегородок | Существенные другие слои |
|---|---|---:|---:|---|
| АР/11 | План с мебелью, 140 м² | 1 690 | — | 10 073 зоны, 3 125 мебель |
| АР/16 | Кладочный план 1 этажа | 1 242 | — | 641 оси, 417 размеры |
| ПЗУ/3 | План 1 этажа с размерами, 176,57 м² | 1 096 | 172 | 3 171 мебель, 307 зона |

Здесь подсчитаны только физические PDF paths (`type` = `s`, `f`, `fs`) из `get_cdrawings(extended=True)` без служебных записей групп и отсечений; поэтому они отличаются от общих сумм из ранее использованного `pathCount`.

## Новая подготовка для существующего APA Router

Скрипт `scripts/apa_arch_plan_benchmark.py` создаёт PNG-вырезку + JSON с контролем источника в отдельном НОВОМ каталоге. Это независимая READ_ONLY утилита, **не новая встроенная команда**. Не требуется переустановка уже работающего semantic-v1.

| Источник | Стр. | Прямоугольник в PDF пунктах | PNG 144 dpi |
|---|---:|---|---|
| АР Свободный | 16 | 125 95 685 595 | 1120×1000 |
| АР Свободный | 11 | 130 150 560 580 | 860×860 |
| ПЗУ Саратов | 3 | 460 185 1110 545 | 1300×720 |

PNG сохраняет все видимые слои, включая размеры; он **не фильтруется** по слоям. JSON содержит статистику по исходным OCG-слоям для последующей фильтрации. Семантические стены, оконные и дверные проёмы PDF-парсер не устанавливает.

Предварительный эксперимент прошёл на реальных загруженных PDF: все три PNG/JSON созданы, SHA входных PDF стабильны. CI Windows 3.11/3.12 использует синтетические исходные PDF, без пользовательских файлов.

Следующий шаг: обработать 3 полученных PNG установленной моделью OpenBIM M2 через `AddOn.APASemantic.OpenBIMSegments` (без повторной установки) и сравнить массивы `classPixelCounts` и регионы. Для Raster2Seq нужен отдельный подтверждённый локальный инференс, не путать с успешным Windows vendor import.
