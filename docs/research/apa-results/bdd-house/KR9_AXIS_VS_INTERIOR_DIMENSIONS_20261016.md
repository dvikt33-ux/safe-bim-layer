## Независимые подтверждённые цепочки КР-9
- Размеры по осям: X = 5.340 + 1.430 + 1.930 + 5.580 = **14.280 м**, Y = 1.090 + 8.290 = **9.380 м**.
- Наружная размерная цепочка: **14.580 × 9.680 м** (отмечена на листе КР-9).
- Внутреннее разбиение северной линии: **3.430 + 0.100 + 3.520 + 0.100 + 2.120 + 0.100 + 4.810 = 14.180 м**.
- Внешний размер 14.580 минус две наружные стены/связки по 0.200 = 14.180 м. По Y аналогичное вычисление 9.680 - 2×0.200 = **9.280 м**.
- Общие данные (PDF стр. 3) ошибочно называют 14.180 × 9.280 **размерами в осях**. Совпадение с внутренним размером чрезвычайно сильное, но уточнение формулировки остаётся инженерным выводом по размерным цепочкам, а НЕ официально исправленным листом.

## Материалы/конструкции и что ещё требует сверки
- КР-9 различает **ОБ1** — опорная обвязка из доски 200×50 мм и **ОБ2** — из доски 100×50 мм. Это исходные конструкции, а НЕ обобщённая толщина готовой отделанной стены.
- КР-10 содержит стойки **СТ1** 200×50 мм и **СТ2** 100×50 мм; фактическая наружная сборка многослойная. В описании проекта отмечены слои утепления 200 мм и 50 мм (PDF стр. 4); проверить последовательность и материалы непосредственно по узлам.
- Созданные в первой native-сборке 6 объектов Wall имеют **Basic thickness 0.250 м** по скрипту. Этот простой тип не воспроизводит каркас+обшивку+утепление как редактируемые зависимости. Нельзя автоматически переклассифицировать в 200 мм или удалять стены, пока не проверены стеновые привязки по реальному PLN.
