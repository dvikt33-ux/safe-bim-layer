## Что реально доступно

Сценарий `scripts/apa_bdd_kr12_two_north_windows.py` использует **существующие** `archicad_project_accelerator.prepare_native_task` (BIM Graph), `archicad_dynamic_commands.DynamicCommands.execute`, `archicad_scene_run.SceneWriter` и **тот же SQLite-журнал**, который подтвердил первое окно (GUID `5C63FA89-C4A9-4EC5-811A-D989CF1D8626`). Никакого нового writer, Tapir REST-клиента, SQLite-хранилища или собственного планировщика.

Проверка перед записью требует 261 исходный GUID + ровно один ранее созданный Window, сохранённое до начала второго этапа рабочее PLN, успешную запись первого окна в SQLite, Archicad 29 build 5101 порт 19727, подлинный SHA исходного PLN, Native Wall geometry и отсутствие предыдущих попыток создать новые окна.

Сохраняется отдельная побайтовая резервная копия рабочего PLN, перед каждой из двух Native CreateWindows остаётся барьер целостности модели и сигнатур. Две команды помещаются в **существующий SceneWriter**, каждая с новой уникальной сценой и отдельной коммитнутой SQLite-записью до отправки в Archicad. После каждой фиксируются ровно один GUID окна, правильная нативная геометрия, владелец и изменённый BREP стены; остальные элементы не должны измениться.

## Один запуск PowerShell

Перед этим **сохранить Ctrl+S** только рабочую копию `BDD дом - по чертежам 2022.pln` с первым окном; первый Window Live PASS из отдельной квитанции имел `savedToPLN=false`.

```powershell
$ErrorActionPreference = "Stop"
$branch = "feature/apa-bdd-north-two-windows-20261016"
$folder = Join-Path $env:TEMP ("APA_BDD_NorthPair_" + [DateTime]::UtcNow.ToString("yyyyMMdd_HHmmss"))
gh repo clone dvikt33-ux/safe-bim-layer $folder -- --depth 1 --branch $branch
if ($LASTEXITCODE -ne 0) { throw "Не удалось получить APA" }
$py = "$env:APPDATA\uv\tools\archicad-mcp-server\Scripts\python.exe"
& $py (Join-Path $folder "scripts\apa_bdd_kr12_two_north_windows.py") --apply --publish
Write-Host "APA_NORTH_EXIT_CODE=$LASTEXITCODE"
```

При двух подтверждённых LIVE PASS нажать **Ctrl+S** в том же рабочем PLN. Если ошибка, не повторять: смотреть автоматический отчёт `safe-bim-bridge/safe-bim-mailbox/gpt-live/results/apa-bdd-apa-north-windows-*.json` и существующую SQLite-квитанцию. `main` не изменяется, исходный PLN не изменяется.
