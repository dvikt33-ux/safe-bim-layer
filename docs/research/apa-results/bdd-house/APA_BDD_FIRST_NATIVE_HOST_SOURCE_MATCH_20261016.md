## Следующая реальная BIM-операция APA

Не создавать новую внешнюю стену: фактические 6 GUID уже существуют. Для разделённых блоков 1.2—1.5 и внутренних 1.9—1.23:
1. Оцифровать положение каждой стойки/проёма по КР-10/развёртке; исходное значение в метрах и направление;
2. Квалифицировать (\mathrm{centerOffset}), тип Window/Door, размер, отметку нижней грани, orientation и зазоры;
3. Проверить точное владельческое `Wall` и возможность host в живом Archicad (включая библиотечные детали);
4. Компилировать зависимость через уже существующий `archicad_project_accelerator.prepare_native_task()` и `DynamicCommands.prepare_workflow()`;
5. Выполнить строго ограниченный шаг через **уже существующий SceneWriter**, GUID-retention, журнал `intent-before-write` и независимый native readback;
6. Только после успешной проверки применить остальные согласованные source opening, затем кровлю.

**НЕЛЬЗЯ:** ретранслировать 23 исходных конструктивных блока в 23 хаотичных Basic Wall; самостоятельно придумывать `centerOffset`; повторять старые отдельные Tapir-модули. Следующие изменения ещё не производились.
