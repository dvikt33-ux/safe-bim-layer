## Что не следует путать с доказанным ускорением APA

**LFM2.5-24B-A2B:** заявлено высокое качество агентных tasks (LiveClaw 48.09 vs Qwen3.6-35B-A3B 38.19), но это сравнение только из публикации разработчика. На RTX 4060 8GB все 13.6–14.5 GB весов не поместятся в GPU — необходим CPU/GPU offload и дополнительные KV/context RAM. Частичная гипотеза: GPU веса ~5–6GB, в RAM ~8–10GB, плюс контекст и Archicad, зависит от точной схемы offload, НЕ измерено. Значения общей RAM и оставшегося из 48 GB при открытом Archicad должны быть фактически измерены. **Не обещать скорость** и не сравнивать с Strata 125B и Gemma 4 на чужом GPU.

**ColGrep-Agent:** vendor claims на **52 задачи поиска по коду, 13 репозиториев, 624 прогона**: ~34% меньше API tokens, ~40% меньше cache-aware API costs, но **время поиска увеличивается**. Это НЕ бенчмарк исправления кода / BIM. Сам продукт делится на ColGrep поисковый Rust CLI, ColGrep-Agent 2B и embedding LateOn-Code-edge. Windows готовый бинарник заявлен CPU-only; для Vulkan/GPU может потребоваться cargo build, а не «одним кликом». Ни в коем случае не запускать без проверки удалённые установочные PowerShell pipes. APA имеет собственный research-only MCP retrieval gateway и индексатор; A/B **сначала**, не создавать дубли.

**Llama Windows:** WinUI3 wrapper llama.cpp, MIT. Может устранить сложность локального запуска, но само по себе не ускоряет математику inference, может конфликтовать с уже работающим Strata/другим сервером.

**OCR:** чтение нормативных сканов, таблиц и схем в документах; **PDF→BIM оставить в конце roadmap**, не считать автоматическим пониманием российского СП и не создавать BIM из распознанного PDF.

**UltraBERT / UIBK:** English only. Наши нормативы и документы часто русские: benchmark RU обязателен, сейчас у них нет подтверждённого RU качества; UIBK требует trust_remote_code=True для PyLate: security audit.

**NVIDIA Bolt:** анонсированный срок 15.10 — не значит файл уже доступен. 24GB Q2 превышают VRAM 8GB, а при offload нагрузка на RAM существенна; не ставить до подтверждённого build/quant.

**Microsoft-Decision-1 / Muse Wonder / Gemini Argon:** проверены как реальные объявления, но не проходят условие бесплатной локальной интеграции. Не предлагать тарифы.

### Следующая партия коротких измерений без сотен тестов

1. **LFM2.5:** 8 real-source APA tasks (tool JSON, C++/Python defects, schema-grounding, refusal to fabricate Archicad readback) против Gemma 4/Strata baseline; RAM/VRAM/TTFT/decode tok/s/time/error, no live writes. Без лицензии на distribution не упаковывать в APA.
2. **ColGrep:** 20 реальных вопросов по текущему APA repo, заранее размеченные file+line ground truth; сравнить с существующим apa_retrieve/SQLite FTS, scoped GitHub search и ripgrep, time/tokens/accuracy/CPU-RAM.
3. **Llama Windows:** non-invasive test localhost:9931 vs existing server; if no UX/time gain, skip.
4. **LightOnOCR-3-0.8B:** 5 сканированных страниц/таблиц с ручным эталоном; читать только нормативные документы, не генерировать чертежи.
5. **UltraBERT/ UI BK:** только после A/B для 20-50 англоязычных SDK doc queries, не внедрять без победы над FTS.
