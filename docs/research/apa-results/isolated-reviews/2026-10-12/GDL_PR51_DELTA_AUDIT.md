## 3. Four residual gates and risk classification

### G1 — name-to-Main-ID parity at the actual native CreateObjects boundary (HIGH for scale-up)
`prepare_object()` checks the filtered inventory's name and GUID; SceneWriter subsequently dispatches **name only**. The audit located **no pre-dispatch matching call through the same native search flags** used by `CreateObjects` in these pinned files. Archicad's documented name search can be nonunique, and the reported 92 skipped catalog entries remain unknown. The *post*-placement `ownUnID` check catches identity mismatch but does not prove write avoidance. **Mitigation:** source-inspect native `CreateObjects` resolver or expose a read-only same-resolver exact-query command with `createIfMissing=false`, onlyPlaceable=true, expected Main ID, missingDef=false and exact project binding immediately before dispatch. Block **generalization** until parity evidence; preserve the accepted isolated result without asserting a current mismatch.

### G2 — typed GDL parameters and persistent revision/macro closure (HIGH for reusable components)
`verify_object()` checks Main GUID and native details; `verify_geometry()` reads body vertices. Neither calls `GetGDLParametersOfElements` for a complete typed-value equality check, nor binds the selected package's Revision ID, macro Main IDs/dependencies and UI behavior into the durable placement plan. Main GUID alone identifies functional family, **not exact packaged revision**. Work itself reports historical UI-macro GUID mismatch and visible UI NOT_VERIFIED. **Mitigation:** for the *same* existing placed GUID, collect exact parameter names/types/values and revision/macro records before and after reopening the authorized isolated PLN, compare against an immutable package manifest. Do not describe a 340 mm parameter as 340 mm physical envelope when native vertices measure 310 mm.

### G3 — selected import provenance and hidden inventory collisions (MEDIUM; tighten before any other package)
`import_selected()` computes local SHA-256 for listed input files and checks again before import; `overwriteExisting=false` and a pinned output prefix are good guards. However, the observed API result does not independently prove an embedded-file *post-import content hash*. With partial catalog coverage, `catalog['libraryParts']` absence does not prove the same name/Main GUID is absent everywhere; readback of the successfully selected item does not prove global catalog completeness. No code-level independent rights audit of the other 151 manufacturer source LCF files is claimed. **Mitigation:** no whole-library import; require owned source manifests, explicit licensing review, and read-back of inserted file manifest/content when safely available.

### G4 — optional custom GDL factory itself still SOURCE_NOT_VERIFIED (DEFER)
The earlier #49 saved schema advertises `SafeBIMGlobalLibraryPart`/`CreateLibraryPartFromScripts`, but #51's selected GSM import is a **different capability**. Do not interpret successful `AddFilesToEmbeddedLibrary` as evidence that native GDL compilation or `LP_XMLConverter` execution works. Source/binary parity, `Discover/Inspect` side-effect classification, compilation reproducibility and ABI are still unresolved. **Defer new factory build** until there is a real use case that cannot be served by the selected-package adapter.
