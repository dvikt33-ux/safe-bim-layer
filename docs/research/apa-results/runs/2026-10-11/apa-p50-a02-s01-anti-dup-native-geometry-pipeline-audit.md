**Recommendation to independent auditor:** **DO NOT ACCEPT AS ORIGINALLY WORDED.** Mark `NEEDS_RESCOPE` / `DEFERRED` (rather than prematurely inventing a new task) and define only the verifiable integration delta under existing `APA-P30.A02.S01/S02` if it fits: connect pre-existing JSON intent to generic per-element operations, reuse one shared SceneWriter ledger and per-project attribute resolver, verify runtime feature set, add full negative tests. This does *not* require new planning engine, new native API, duplicate catalog, or new independent execution service.

## Minimal integration delta and acceptance gates

1. **No writes:** enumerate existing modules and contracts; select **one** owner of intent and **one** owner of durable execution. Read provenance and test parity (same GUID/material/story semantics). Existing P30 tasks may suffice; no new S-ID without independent audit.
2. **Extend `compile_intent`:** allow an array of independently typed components with explicit dimensions/stories/material roles instead of `len(components)==1` and only `pavilion-frame-v1`. Compile to existing `archicad_bim_graph.compile_graph`; no fresh DAG.
3. **Resolve current-project attributes:** call existing template-builder/material lookup; fail-closed unknown/multiple candidates; Basic thickness explicit, Composite skin-derived; Surface overrides separate from BM. Support `GetProfiles` limitations from earlier P10.A01.S02.
4. **Bind to existing verified runner:** same target PLN guard, schema hash, SQLite journal, GUID/readback, per-element collision scan, rollback/recovery states; adapt per-element operation verification for generic walls/slabs first. For old Tapir snapshot direct Basic CreateSlabs unsupported: reuse proven Create→Modify strategy **only** with durable one-shot reservation, clear not-atomic caveat, and readback; do not replay uncertain writes.
5. **Evidence gates:** positive/negative offline unit tests, no accidental supported capability claims, one explicitly approved expendable PLN live single-element geometry test, save/reopen independent 12-GUID-style audit. Reported fixed pavilion success **does not automatically validate** generic adapter.

**Prohibited:** Changes to main/master, installed APX, prior published tested branch or user's saved pavilion as part of source audit; no repeat of old v1.3 menu 5/v1.4 recovery. Extra C++/MCP/OR-Tools not justified until current Tapir workflow fails a tested requirement.
