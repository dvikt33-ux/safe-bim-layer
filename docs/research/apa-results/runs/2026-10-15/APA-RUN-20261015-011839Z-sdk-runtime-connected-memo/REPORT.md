# APA: verified SDK reads and connected native memo analysis

APA now reads actual Roof/Slab parameter topology and element hotspots through grouped SDK queries, then passes the captured contours and holes through the existing BIM Graph to the existing Shapely adapter. No second writer, geometry engine, Knowledge Graph or controller was added. The PR is based on exact PR #88 head `a444d5a6b481bfabd9c48f23c17df05c51ab0ea4`.

The authorized PR #88 candidate was loaded and all six added SDK/DevKit queries were registered, called and checked against typed results. Their scoped evidence covers twelve tool-default headers, four polygon memos, stable project-unit preferences, the ungrouped case, library origin/name and a suppressed eight-boolean license query. Nested group roots, complex default geometry and license identifiers are not accepted by these checks.

Four further SDK contracts were connected using the existing registration overlay and functional manifest:

| Group | Actual native result | Remaining limit |
| --- | --- | --- |
| Envelope memo | Seven Roof/Slab polygons match independently read coordinates, holes and stories | No Shell sample; parameter memo is not resultant BREP; side-material/edge-trim/pivot overrides and Shell frames are not serialized |
| Drawing associations | Two real Drawing links read; both Drawing targets independently found, one linked GUID found in current ViewMap | Both update-status/content-box queries returned native errors; legacy Drawing GUID differs from source-link GUID and is not treated as equivalent |
| Element hotspots | 179 native hotspots from four walls; both reference-line endpoints independently matched on every wall | Hotspots are not body vertices or a collision proof |
| Quantities | Registered, but the first Wall/Slab/Roof/Stair batch crashed AC29 | **QUARANTINED** in APA dispatch and the native entry; no replay and no quantity PASS |

The quantity crash produced `C0000005 ACCESS_VIOLATION` in Archicad. The failing element and root cause remain NOT_VERIFIED. The public proof contains only the crash-report hash and sanitized facts. The unsafe tested binary is identified separately from the safe rebuild. The rebuilt native quantity entry returns a typed refusal before entering the quantity engine; Python blocks execution for both source-added and already exported command names. Generated quantity accessors are staged, unused code rather than a functioning quantity feature.

The common catalog contains **382 preparable contracts: 372 native/official/source and 10 local**. This includes blocked and source-only contracts. The original restored runtime has 264 add-on registrations plus 73 compatible official contracts, or **337**. The tested PR #88 candidate had 281 add-on registrations; the later tested prototype had 285, or **358** with compatible official contracts. Registration does not prove every command callable. This pass verified **nine distinct SDK/DevKit queries** across the two tested binaries; the quantity query failed. Thirteen DevKit examples remain source-only, the legacy `GetNativePhysicalGeometry` command is missing in the candidate, and all 32 other installed APX still lack independent public command contracts. The provider matrix retains their exact prior blockers without counting SDK declarations as commands.

`MemoPolygonInputs` converts straight Roof/Slab memo contours to the existing `PolygonRelations` input, preserving GUID/story/type bindings separately. Curves are explicitly omitted, not approximated. The existing graph resolves the typed result pointer directly. The actual seven-element memo flow preserved two holes; all seven coordinates/holes also matched the old native read adapter. This is 2D parameter-footprint analysis and grants no native write permission. A reproducible saved-data entry point is `scripts/apa_native_memo_flow.py --memo <captured-result> --output <proof>`.

The two PR #87 registration defects are fixed: provider batches commit atomically and ambiguous common-schema names receive distinct aliases without rewriting previous contracts. Seven focused checks cover the changed adapter and safety contracts; broad regressions run in Windows GitHub Actions. The independent PR #89 audit is not duplicated locally. New SDK schemas bind code-owned source/include hashes; dependencies and full schemas remain lazy through the existing main orchestrator and Knowledge Graph.

After the crash the original APX and registration were restored. The saved file matched the pre-probe control copy. Reopening it read-only independently retained **all 258 GUIDs and serialized native parameters**. No model-write API was invoked. An earlier close/open changed saved-file bytes before SDK calls; that cause remains NOT_VERIFIED. No before/after resultant BREP comparison was performed. The final safe rebuild passes full Release compile/link and embedded binary/source identity checks and has not been installed. Evidence is under `docs/evidence/APA_*SDK*.json` and `APA_*MEMO_FLOW.json`; raw paths, PLN, binary and crash dump remain local.
