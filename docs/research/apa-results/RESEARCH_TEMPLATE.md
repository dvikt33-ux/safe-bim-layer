# APA — обязательный шаблон одного исследовательского прохода

Каждый исследователь (чат, Deep Research, человек, runner) перед началом читает MASTER_PLAN, CURRENT_STATUS, ARTIFACT_REGISTER и BRANCH_REGISTRY. Каждый проход = **один подшаг S-ID**. Файл отчёта создаётся в runs/YYYY-MM-DD/ с уникальным именем и только в канонической ветке.
