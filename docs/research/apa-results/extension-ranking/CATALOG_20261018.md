# APA / Archicad 29 — реестр готовых расширений и критических пробелов (18.10.2026)

**Цель:** закрывать функции APA штатными командами Archicad, готовыми дополнениями и библиотеками; **не писать альтернативные реализации** имеющихся функций. Этот отчёт — исследование, а не приёмка или установка.

**Исходные условия:** Archicad 29 / Windows 11 / RTX 4060 8 ГБ / 48 ГБ ОЗУ; без обязательных покупок, второго писателя PLN и изменения `main`. Не начинать Archicad 30, пока не стабилизирована версия 29.

**Прозрачность источников:** первичные страницы Graphisoft, Speckle, BIMcollab, IfcOpenShell и Raster2Seq ранее открывались **через Opera**, что подтверждало заявленные функции. В текущем запросе Opera Connector отключён. Кандидаты с отметкой `HISTORIC_SOURCE_AUDIT` основаны на предыдущем исходном аудите `ai-candidates/FREE_READY_EXTENSIONS_20261014.md` и `ARCHITECHTURES_OPEN_SOURCE_REUSE_AUDIT_20261015.md`, а не на новой живой проверке. Состояния `SOURCE` или `CODE_PREPARED` **не равны** рабочей приёмке.

## Правила внедрения

1. Сначала проверить, нет ли аналогичной функции в текущем установленном Archicad и уже подключённом APA. В этом случае `REUSE`, без новой установки.
2. Для дополнений сохранить ссылку производителя, версию, контрольную сумму, тип лицензии, способы вызова и условия использования. Не считать наличие кнопки эквивалентом программного интерфейса.
3. Если у внешнего инструмента нет готового совместимого интерфейса к текущему APA — не разрабатывать второй исполнитель: статус `API_NOT_AVAILABLE` или `NOT_TESTED`.
4. Для файлового анализа применять только копии исходных PDF/IFC, запись в модель запрещена. На копии PLN сначала выполнить чтение, затем отдельную санкционированную запись, контроль GUID/BREP/атрибутов, сохранение и повторное открытие.
5. Операции с уже неопределённым исходом не повторять, не очищать журнал вручную.
6. Любая модель распознавания проходит измерения на фактических листах BDD, отдельно: точность стен/окон/проёмов/масштаба, время, память и ресурсы видеокарты; без фактической проверки — `NOT_TESTED`.
7. Не объявлять завершёнными инженерные расчёты и российские нормативы на основании только успешной IFC-валидации.
8. Обновление официального плана №182 выполнить только после привязки каждой реально принятой возможности к задаче, журналу и первичным результатам.
