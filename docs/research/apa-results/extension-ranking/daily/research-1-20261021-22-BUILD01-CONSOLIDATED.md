## Решения и ограничения
1. **G0 — точный build.** Официальный Graphisoft Python API29 `GetProductInfo()` даёт сведения о версии, сборке и языке. №2: получить реальный read-only ответ именно экземпляра на рабочем порту, проверить build 5101. Источник: https://archicadapi.graphisoft.com/archicadPythonPackage/archicad.releases.ac29.html .
2. **G0 — идентичность APX.** Путь к Archicad.exe не равен пути установленного дополнения. №2: Add-On Manager → фактический путь загруженного APX → SHA-256 Windows; зафиксировать соответствие с локальной схемой. Наличие в архивном JSON не подтверждает загрузку команды.
3. **G0 — регистрация команд.** Штатный `IsAddOnCommandAvailable` годится для read-only preflight, включая `GetModelDumpV1`; не запускать CREATE ради обнаружения. Сопоставить runtime/APX/schema, а не смешивать upstream 1.5.9/1.7.2 с модифицированной локальной 1.5.10.
4. **G0/G1 — идентичность проекта.** Для защищённой записи требуется проверенная scratch-копия PLN, путь, имя проекта, SHA и авторизация. Не считать `GENERATE_FROM_ZERO` созданием проекта: оно может требовать подготовленный native project.
5. **G1 — существующий компилятор.** PR #74 и SceneWriter — единственный приоритетный маршрут; не разрабатывать второй writer. Перечень допустимых дополнительных nativeComponents ограничен; `CreateBeams` и дополнительные `CreateSlabs` не следует считать поддержанными без подтверждения текущего контракта. Источник: https://github.com/dvikt33-ux/safe-bim-layer/pull/74 .
6. **G1 — вырожденные стены.** Проверка координат не равнозначна запрету нулевой длины. №2: определить, закрыт ли случай существующим валидатором, и отклонять нулевые сегменты до записи. Upstream issue https://github.com/ENZYME-APD/tapir-archicad-automation/issues/433 относится к другой версии и не доказывает сбой AC29.
7. **G2 — этажи.** Нельзя предполагать правильную привязку Slab/Column ниже нижнего этажа. №2: readback floorIndex и вертикального смещения, без переноса неподтверждённых upstream fixes. Источник: https://github.com/ENZYME-APD/tapir-archicad-automation/issues/992 .
8. **G2 — Slab/материалы.** В архивной схеме 1.5.10 CreateSlabs и ModifySlabs имеют разные возможности. №2: использовать уже предусмотренный CREATE→MODIFY и проверять итоговый building material/composite, не переносить поля из 1.7.2 автоматически.
9. **G2 — слои.** Для ряда CREATE-команд слой нельзя передать непосредственно. №2: применить существующее изменение свойств и проверить layer readback, не строить новый адаптер.
10. **G2 — крыши.** Контракт PR #74 для Basic Roof ограничивает геометрию, материал и выход контура за bounds. №2: preflight roof outline/pivotLine/материал до нативной записи; не считать PolyRoof автоматически поддержанной.
11. **G2/G4 — окна и двери.** GUID от CREATE не доказывает наличие геометрического Window/Door. №2: проверять фактический элемент, host, effective tool type, library identity и положение. Источник: https://github.com/ENZYME-APD/tapir-archicad-automation/issues/481 .
12. **G2 — Favorites.** При применении Favorite могут теряться отдельные настройки Composite/Top Link; часть ошибок вызвана отсутствующими обязательными параметрами. №2: readback всех критических полей. Источник: https://github.com/ENZYME-APD/tapir-archicad-automation/issues/766 .
13. **G2 — библиотеки.** Архивная схема 1.5.10 различает raw и effective tool type; нельзя переносить более узкую схему upstream 1.5.9. №2: подтвердить доступность и идентичность Library Part в установленном экземпляре.
14. **G4 — сохранение.** `SaveProject` 1.5.9 и 1.7.2 отличаются; не передавать новый `projectPath` в 1.5.10 без runtime-проверки. Использовать уже существующий GuardedSave; обязательны Save/Open и повторный GUID/geometry readback.
15. **G4 — геометрия.** `GetModelDumpV1` может быть пользовательской командой, отсутствующей в архивной схеме; отсутствие в JSON не доказывает отсутствие в APX. До запуска нативного аудита проверить регистрацию и зависимости; не смешивать API ModelAccess с установленной Tapir-командой.
16. **G4 — независимые средства.** Штатные Graphisoft `GetComponentsOfElements`, `GetPropertyValuesOfElementComponents`, SDK29 `GetConnectionTable` пригодны как кандидаты для независимого контроля, но доступность в локальном окружении требует подтверждения. Источник: https://archicadapi.graphisoft.com/archicadPythonPackage/archicad.releases.ac29.html .
17. **G4 — ложные дефекты.** Утверждение о массовом дефекте L-образных соединений стен было отозвано автором после перепроверки: https://github.com/ENZYME-APD/tapir-archicad-automation/issues/1042 . Не включать его в доказанные блокеры.
18. **G4 — ограничения версии.** Issue о пустых телах Column/Beam в Tapir 1.7.2 не переносится на 1.5.10 без теста: https://github.com/ENZYME-APD/tapir-archicad-automation/issues/1296 .
