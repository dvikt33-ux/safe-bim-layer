# APA — углублённый многопроходный аудит готовых решений (18 октября 2026)

**Режим:** только поиск/проверка первоисточников через Opera, анализ опубликованного кода и отчётов GitHub. **Никакой установки, записи в PLN/APX или изменения main.** Исходный реестр расширений расположен в `candidates.json`, машинные оценки являются приоритетом рассмотрения, а НЕ фактом эксплуатационной надёжности.

**Цель владельца:** максимально закрыть функции ускорителя подключением готового штатного инструмента/библиотеки/расширения вместо создания собственной реализации. Не ставить второй BIM-исполнитель, журнал транзакций, геометрическое ядро или диспетчер. Приоритет — установленный Archicad 29; Archicad 30 исключён из текущего внедрения.

## Метод и границы доказательства

Каждый тематический проход проверял следующие независимые ворота: **(1)** реально существующий инструмент и конкретная функция на странице первоисточника; **(2)** лицензия, стоимость и применимость в проекте без дополнительного бюджета; **(3)** совместимость с Windows 11 / Archicad 29 и реально доступный программный интерфейс; **(4)** совпадение геометрии, состава и параметров с исходной моделью; **(5)** отсутствие дублирования установленного APA; **(6)** возможность доказательной локальной проверки на копии файла. Неизвестные характеристики помечаются `NOT_VERIFIED`. «Есть код» ≠ «установлено» ≠ «работает в живом Archicad» ≠ «инженерно принято».

## Жёсткие ограничения при ранжировании

- **Безопасность исходной модели:** никогда не ставить непроверенный APX прямо в работающий BDD. Тестировать на побайтовой копии PLN с независимыми хешами, до/после GUID, владельцами, материалами, BREP, сохранением и повторным открытием.
- **Без вторых исполнителей:** внешняя библиотека передаёт результаты в *уже существующие* DynamicCommands / BIM Graph / SceneWriter. Наличие API не означает разрешение на прямые модельные изменения.
- **Без вымышленных метрик:** выигрыш «×100» не объявлять без замеров времени и числа нативных вызовов на одинаковой сцене.
- **Без платной зависимости:** Rhino, Solibri, закрытые архитектурные генераторы и другие решения с обязательной лицензией не входят в бесплатную производственную сборку APA.
- **Без ложного закрытия норм:** анализ геометрии, энергорасчёт и IFC/IDS в отдельности не обеспечивают российскую экспертизу.
- **Ограничение железа:** RTX 4060 8 ГБ VRAM и 48 ГБ ОЗУ; нейросети проверять отдельно по VRAM/ОЗУ. Twinmotion во время рендера может использовать всю VRAM, поэтому параллельные модели не считать безопасными без замера.

## Итоговые решения

1. **Прямо сейчас не писать ничего нового** для копирования групп: использовать уже имеющуюся нативную реализацию и завершить сквозную приёмку №162.
2. **Качество источника важнее рейтинга:** PDF/растр/BIM нейросети остаются экспериментальными, а реальная геометрия и точные координаты из АР/КР подтверждаются источником.
3. Ввести в короткий список к точечной проверке **ezdxf, IfcConvert, PyNite, EnergyPlus/OpenStudio, ifc2plan**; последовательно сравнить с установленными модулями, чтобы избежать дублей.
4. **Большинство штатных функций Archicad не требует плагина**: оси, геометрические коллизии, виды/макеты/публикация, связные модули, группы.
5. Считать непроверенные лицензии, Windows-совместимость и наличие программного доступа блокирующими критериями: статус `SOURCE_ONLY` не повышать по аналогии.

**Объём:** 16 тематических циклов с первичными документами, сопоставлением с реальными материалами APA и контрольными ворота́ми; численный рейтинг отдельных кандидатов — в машинном реестре. Проходы являются **исследованием источников**, не локальными или нативными тестами.
