## C1756-03 [P0] Два штатных стоп-крана вместо нового sync-engine
**Операция:** прекратить GH пересчёт при настройке входов и не отправлять частичные изменения в Archicad. **Готовое:** Rhino8 `-Grasshopper → Solver Disable/Enable`; штатный GH Boolean Toggle→`Synchronize` для AC Design Component. **Направление:** управление GH solver и GH→AC output; не distributed transaction, не AC rollback. **Ограничение:** Solver Disable глобален для GH-сессии; Boolean False не удаляет старые элементы и не гарантирует что другой writer не работает. **№2:** описать последовательность freeze→полные входы→read-only schema/target check→после отдельного G3 разрешения один Sync→readback→freeze. Для APA-owned GUID вообще не включать GH native writer, только JSON→SceneWriter. **ГОТОВО:** ноль частичных записей, целевые GUID неизменны; сейчас SOURCE_ONLY.
