## Главное новое

1. Официальный Graphisoft Archicad 29 C++ API содержит ACAPI_Markup_ImportFromPDF (Since Archicad 29), ACAPI_Markup_ImportFromBCF, ACAPI_Markup_ExportToBCF, ACAPI_Markup_GetList. ImportFromPDF импортирует ЗАМЕЧАНИЯ из PDF, созданного Archicad; APIERR_BADNAME исключает сторонний PDF. Это не PDF→BIM.
2. IfcFM в pinned исходниках IfcOpenShell предоставляет COBie24/basic handover в CSV/ODS/XLSX, но отсутствует как отдельный кандидат в каталоге 61. Обнаружены риски silent overwrite при duplicate_keys и silent skip при federate.
3. AC29 UI поддерживает BCF 3.0/2.1/2.0; IfcClash в pinned исходниках экспортирует bcf.v2; отдельно существует bcf.v3 API. У bcf-client pyproject GPLv3 classifier при LGPLv3+ в общем каталоге: лицензию нельзя считать разрешённой.
4. IDS AC29 Import Properties and Classifications — импорт схемы свойств, не IFC QA. IfcTester делает XML validation и отдельно IFC model validation, умеет JSON/HTML/ODS.
5. SAF AC29 — готовые штатные переводчики/каталоги сечений, но каноническая задача A11.S08 BLOCKED, расчетный движок и программный SAF API не подтверждены.
