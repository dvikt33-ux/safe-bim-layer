Первичные ссылки:

| Команда | Вход | Выход | Ранняя подтверждённая версия |
|---|---|---|---|
| CreateGroups | elementGroups[]: elements[] с elementId/groupId; optional parentGroupId | groupGuids[]: groupId либо ошибка для каждой группы | 1.4.0 |
| GetGroupsOfElements | elements[]: elementId | groupGuids[]: groupId либо ошибка | 1.5.6 (нет в 1.4.0) |
| GetElementsOfGroups | groups[]: groupId | elementsOfGroups[]: elements либо ошибка | 1.5.6 (нет в 1.4.0) |
| CreateHotlinkNodes | hotlinkNodes[]: sourceLocation обязательно; name, storyRangeType, refFloorIndex опционально | hotlinkNodes[]: hotlinkNodeId + existing либо ошибка | 1.5.9 (нет в проверенных 1.4.0/1.5.6) |
| CreateHotlinkInstances | hotlinkInstances[]: hotlinkNodeId, origin обязательны; rotationAngle, mirrored, floorIndex, floorDifference, layerIndex, skipNested, suspendFixAngle, ignoreTopFloorLinks, relinkWallOpenings, adjustLevelDiffs опционально | elements[]: instance elementId либо ошибка | 1.5.9 (нет в проверенных 1.4.0/1.5.6) |

Ранние версии — только минимальные среди **просмотренных** тегов, не доказательство абсолютной даты появления. CreateGroups использует ACAPI_Grouping_CreateGroup внутри общего undoable command, но каждая группа получает собственный результат; общий успех не гарантирует успех всех. Для GetGroupsOfElements несгруппированный элемент даёт ошибку, не пустой GUID. В CreateHotlinkInstances rotationAngle — радианы; floorIndex по умолчанию текущий этаж; часть опций наследуется от текущего hotlink tool, если не задана. **Node GUID отличается от instance GUID.** Для перемещения hotlink instance предусмотрен ChangeHotlinkInstances, обычный MoveElements может не сработать (комментарий исходника описывает AC28; AC29 LIVE не проверен).

Лицензия Tapir: MIT (прочитан https://raw.githubusercontent.com/ENZYME-APD/tapir-archicad-automation/1.5.9/LICENSE). AC29 исходный API-путь вероятен, **локальная регистрация в установленной 1.5.10 NOT_VERIFIED**.

Сопоставление с PR #162: уже есть CloneNativeGroupV1, CreateNativeGroupV1, sourceRef, memberGuids, проверки BIM-подписи, этажа, точных координат, зависимостей и readback; группы Column/Beam/Object, до 32 placements, до 200 создаваемых элементов. Превью nativeWritePermission=false. Требуется интеграционный readback через существующий SceneWriter, не вторая реализация.

## R1-03. Raster2Seq — Windows и VRAM
README: https://raw.githubusercontent.com/Cornell-VAILab/Raster2Seq/master/README.md ; LICENSE: https://raw.githubusercontent.com/Cornell-VAILab/Raster2Seq/master/LICENSE — прочитаны через Opera. Код MIT. Официально испытано на **Linux**, Python 3.10.13, PyTorch 2.3.1, CUDA 11.8; требуются сборка custom modules через sh make.sh и python setup.py build develop. Вход RGB-изображение, выход замкнутые 2D-полигоны комнат в координатах изображения — не редактируемые стены/окна AC29. Веса перечислены на https://huggingface.co/haopt/Raster2Seq (s3d-bw, cubicasa5k, raster2graph, raster2graph-512, s3d-density). Хеши и лицензия весов отдельно, измеренная VRAM, нативный Windows 11/WSL2 запуск, точность на BDD PDF — **NOT_VERIFIED**. Официального turnkey Windows пути в README нет: **BLOCKED_AS_READY_WINDOWS_SOLUTION**, но не «технически невозможно». Не скачивалось и не устанавливалось.
