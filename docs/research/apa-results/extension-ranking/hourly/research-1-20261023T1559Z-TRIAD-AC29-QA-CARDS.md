# APA №1 — семь карточек готовых возможностей / ограничений, research-1-20261023T1559Z-TRIAD-AC29-QA
**BUILD-01:** это готовые средства проверки и вспомогательного обмена, а НЕ новая система синхронизации и НЕ второй writer. Лицензия: встроенные функции требуют действующий Archicad 29; Rhino 8 требует собственную лицензию; Graphisoft GH-AC connection отдельный официальный add-on, локальное наличие неизвестно.

## C1559-01 — .3dm Hotlink + Update + Model Compare [P0, SOURCE]
Операция: менять сложную геометрию в Rhino, обновить геометрическую подложку AC29 и визуально выявить новые/удалённые/изменённые объекты. Контракт: File→External Content→Place Hotlink (*.3dm); Hotlink Module Manager→Modified→Update→Compare Models. Направление Rhino file→AC geometry (ручное подтверждение), НЕ native Roof/Wall и НЕ live sync. Источники: https://help.graphisoft.com/AC/29/INT/_AC29_Help/120_Interoperability/120_Interoperability-43.htm; https://help.graphisoft.com/AC/29/INT/_AC29_Help/080_Collaboration/080_Collaboration-60.htm; https://help.graphisoft.com/AC/29/INT/_AC29_Help/081_ModelCompare/081_ModelCompare-5.htm. Ограничение: Rhino source помещается как linked object, сегментация и атрибуты требуют QA, relink может очистить Undo. №2: описать точную read-only процедуру и будущий эксперимент сравнения 3DM source before/after; native writer не трогать. ГОТОВО: раздельные снимки Rhino/AC и отчёт Model Compare после санкционированного обновления.

## C1559-02 — Model Compare saved PLN snapshots [P0, SOURCE]
Операция: обнаружить случайные изменения/удаления после GH/SceneWriter, независимо от геометрического редактора. Контракт: Design→Model Compare→Current model vs saved earlier model; типы New/Modified/Deleted. Направление AC snapshot↔AC snapshot, сравнение, без записи. Источники: https://help.graphisoft.com/AC/29/INT/_AC29_Help/081_ModelCompare/081_ModelCompare-1.htm; https://help.graphisoft.com/AC/29/INT/_AC29_Help/081_ModelCompare/081_ModelCompare-3.htm. Ограничение: сравнивает 3D, не 2D, зависит от вида/времени, не подтверждает GUID сохранность и не заменяет API readback. №2: включить в G4 как дополнительный независимый UI-аудит до и после Save/Open. ГОТОВО: нет неожиданных удалений и изменённых конструкций; GUID проверяются отдельно.

## C1559-03 — Native Collision Detection [P0, SOURCE]
Операция: найти столкновения новых стен, перекрытий, колонн, кровли, MEP и проверить headroom. Контракт: Design→Model Check→Collision Detection, Group1/Group2, Volume/Surface tolerances, Check→Model Check Report. Направление AC model→QA report. Источник: https://help.graphisoft.com/AC/29/INT/_AC29_Help/080_Collaboration/080_Collaboration-64.htm. Ограничение: скрытые слои и выделение сужают проверку; SEO/priority junctions исключаются; не является российской нормативной экспертизой. №2: подготовить fail-closed преднастройки видимости/сброса выделения/единиц и фиксируемые допуски. ГОТОВО: воспроизводимый отчёт на полном наборе видимых элементов.

## C1559-04 — Physical Model Quality Check [P0, SOURCE]
Операция: выявить недосоединённые сердечники стен/плит, малые зазоры несущих элементов и аномальные отношения размеров. Контракт: Design→Model Check→Physical Model Quality→Check. Направление AC native→QA report. Источники: https://help.graphisoft.com/AC/29/INT/_AC29_Help/092_ModelCheck/092_ModelCheck-2.htm; https://help.graphisoft.com/AC/29/INT/_AC29_Help/092_ModelCheck/092_ModelCheck-3.htm. Ограничение: зависит от структуры Core, visibility/selection, часть ratio-порогов основана на Eurocode и не заменяет СП. №2: предложить G4 read-only контроль Wall↔Slab junctions и отделить инженерные замечания от нарушений нормативов. ГОТОВО: отчёт с классификацией каждого отклонения.

## C1559-05 — IDS import as BIM property schema [P1, SOURCE]
Операция: заранее задать BIM-свойства/классификации для стен, дверей, кровель, затем проверить экспорт IFC. Контракт: File→Interoperability→IDS→Import IDS, выбор property mapping preset, выбор полей. Направление IDS→AC classification/property definitions→IFC; НЕ импорт значений элементов и НЕ валидатор СП. Источник: https://help.graphisoft.com/AC/29/INT/_AC29_Help/120_Interoperability/120_Interoperability-17.htm. Ограничение: существующие поля не обновляются, частичный импорт возможен при ошибке; изменение проекта требует отдельного разрешения. №2: только описать безопасный шаблон на отдельном TPL, без выполнения импорта. ГОТОВО: схема необходимых свойств, source IDS и перечень конфликтов имён.

## C1559-06 — Rhino Original ID/Layer in Archicad GDL [P1, SOURCE]
Операция: связать импортированную геометрическую подложку с исходным объектом Rhino для read-only provenance. Контракт: AC imported Rhino Object properties Original Layer/Original ID, Find & Select. Направление Rhino .3dm→AC GDL metadata, не AC GUID. Источник: https://help.graphisoft.com/AC/29/INT/_AC29_Help/120_Interoperability/120_Interoperability-41.htm. Ограничение: не работает как подтверждение GUID native Wall/Slab; нет обратного изменения. №2: описать таблицу Rhino ID→GDL object→native counterpart reference с fail-closed на дубликаты; без новых меток в PLN. ГОТОВО: ясно разделены три идентификатора.

## C1559-07 — исключение Solibri Inside и cloud MEP из free P0 [P0 NEGATIVE, SOURCE]
Операция: не строить ложный путь автоматической нормативной QA. Источники: https://help.graphisoft.com/AC/29/INT/_AC29_Help/005_NewFeatures/005_NewFeatures-27.htm; https://help.graphisoft.com/AC/29/INT/_AC29_Help/085_MEPDesigner/085_MEPDesigner-41.htm. ГОТОВО: нет зависимости BUILD-01 от отключённого/лицензионного сервиса.
