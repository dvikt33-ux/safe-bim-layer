## Критическое ограничение MEP

PortBase::Modifier предлагает SetWidth/SetHeight/SetShape, но PortBase::Modify в Graphisoft SDK29 запрещает изменение портов подобъектов RoutingElement, включая Transition. Поэтому получать два ID портов недостаточно для автоматической установки двух разных форм сечения. Нужно исследовать RoutingSegment, RoutingNode, TransitionDefault, а не использовать прямой PortBase::Modify.

SDK29 источник: https://github.com/GRAPHISOFT/archicad-api-devkit/blob/29.3100/docs/class_a_c_a_p_i_1_1_m_e_p_1_1_port_base.html

## Дополнительные интеграционные ограничения

SAF StructuralPointSupport: типы In node/On beam, 6 степеней свободы, Rigid/Free/Flexible/Compression only/Tension only/Non linear, коэффициенты жесткости MN/m и MNm/rad. Для PyNite FEModel3D обнаружены add_node, add_member, def_support, def_support_spring, add_member_dist_load, add_load_combo, analyze_linear; готовая без потерь карта всех типов опор, эксцентриситетов и нагрузок не подтверждена.

NuGet StructuralAnalysisFormat 1.7.3: .NET Standard 2.0, Apache-2.0; зависимости EPPlus>=4.5.3.3, FluentValidation>=10.2.3, UnitsNet>=4.72.0, DI SimpleInjector4/5. Присутствие XLSX import/export не доказывает корректность SAF→PyNite.

СП20.13330.2016: применимость и актуальные изменения №1–6 необходимо проверять по первоисточнику; одного номера редакции недостаточно для выбора коэффициентов. СП50.13330.2024 исключает культовые здания из области применения; пригодность к отдельным вспомогательным корпусам проверяется отдельно.

OFFLINE арифметическая иллюстрация, не физический расчёт: при длине балки 5 м, проекции 4 м и нагрузке 10 кН/м на проекцию итог 40 кН; эквивалентная линейная нагрузка по длине 8 кН/м. Реальный SAF LCS и коэффициенты СП этим не валидированы.

## Аудит A — SDK29 и Tapir
Повторная сверка PortBase, Transition и Tapir NavigatorCommands 1.5.9/1.7.1. PortBase::Modify напрямую не применим к Transition. PublishPublisherSet::GetInputParametersSchema по двум тегам сопоставлен; user-visible selectedNavigatorItemIds пустой по умолчанию небезопасен. Точный локальный Tapir не удостоверен.

## Аудит B — версии, SAF и PyNite
Пересмотрены PyNite FEModel3D.py и pyproject, Tapir MEP 1.5.9/1.7.1, SAF/NuGet/Росстандарт. Результат: даже наличие XLSX SDK и PyNite не означает полной совместимости. Для проектного расчёта обязательны нагрузки, опоры, геометрическая система координат, коэффициенты сочетаний и применимая редакция СП.

## Граф безопасного подключения
AC29 + MEP entitlement (NOT_VERIFIED) → local Tapir runtime (NOT_VERIFIED) → GetMEPPorts + reciprocal QA → SDK29 RoutingSegment shape/size → RoutingNode/TransitionDefault → Transition readback → отдельные LIVE/ACCEPTED ворота. Прямой PortBase::Modify для Transition: BLOCKED.

PublisherSets → идентичность набора → GetNavigatorItemTree(name) → nonempty selection → отдельный outputPath → Publish → output manifest/hash.

AC29 SAM → SAF XLSX → SAF SDK1.7.3 → conversion LCS/Projection/eccentricity/6DOF/factors → PyNite3.2.0 → независимая инженерная проверка. Ни один участок этого графа не имеет LIVE/ACCEPTED в текущем цикле.
