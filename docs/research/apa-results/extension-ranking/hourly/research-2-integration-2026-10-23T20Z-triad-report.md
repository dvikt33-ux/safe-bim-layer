**G4 / P0: найден существующий, не требующий нового writer путь независимого чтения BREP через IFC, но он пока SOURCE_ONLY.** В закреплённой схеме Tapir 1.5.10 (262 команды; Git blob e8ad53b6ea7c19dc34cbdcb723a79be995639cd7) уже присутствуют:
- `GetIFCExportTranslators` v1.5.10 — список имён IFC-трансляторов, READ;
- `GetIFCIdsOfElements` v1.5.1 — явная связка Archicad native GUID → IFC ID и externalIFCId, READ;
- `GetElementsByIFCIds` v1.5.1 — обратная проверка IFC ID → native GUID (external ID может соответствовать нескольким элементам), READ;
- `IFCFileOperation` v1.2.6 — готовый прямой экспорт `method=save`, `fileType=ifc`, `translatorName`, `elementsToExport=EntireProject`. **Файловая запись, НЕ READ**;
- `PublishPublisherSet` v0.1.0 — штатный экспорт заранее настроенного Publisher Set, НЕ READ.

**Особенно важно:** PR74 уже содержит `archicad_bim_documentation.execute_operation` → `SceneWriter.execute_bound_operation` → SQLite для `PublishPublisherSet`! Следовательно, для IFC-публикации не нужен новый writer/router. Но эта существующая защита требует `documentationOperation`, `retainedGuids`, точный `sourceHash`, `saved_sha256`, новый пустой каталог и явные `publisherSetName,outputPath,selectedNavigatorItemIds` (1–4 элемента). Она вызывает `capture_full_model` / `GetModelDumpV1`, **который отсутствует в pinned 262-command каталоге**: пока installed provider не подтвердит такой readback, G4 заблокирован. `IFCFileOperation` в перечне разрешённых `DOCUMENT_COMMANDS` PR74 отсутствует: не обходить журнал прямым вызовом.

**Критический новый риск G4:** Graphisoft AC29 прямо указывает, что Publisher IFC экспортирует **только видимые** элементы, независимо от фильтра транслятора. Поэтому наличие BREP-файла не доказывает полноту здания. Необходима отдельная проверенная 3D View со всеми нужными слоями, стадиями, частями структуры, этажами и включёнными BIM-типами. Иначе применить `IFCFileOperation(elementsToExport=EntireProject)` можно лишь через отдельно разрешённый файловый экспорт; это не текущий защищённый путь SceneWriter.

**Независимый читатель:** IfcOpenShell 0.9.0post1 (LGPL-3.0-or-later) поддерживает OpenCASCADE BRep через geometry iterator / `create_shape`; по умолчанию он выдаёт триангулированную геометрию, для BRep требуется соответствующая OCC-конфигурация/сборка. Это независимый от Tapir парсер IFC, но экспорт всё ещё произведён Archicad. Полностью независимое повторное построение нативного PLN этим не доказано.

## Воспроизводимый G4-контракт без второго исполнителя
1. **G0, только READ:** доказать actual APX SHA/command inventory; `GetIFCExportTranslators`; `GetNavigatorItemTree(navigatorMapId=PublisherSets,publisherSetName=...)`; `GetIFCIdsOfElements` для ожидаемых native GUID. Сопоставить `ifcId` с `IfcRoot.GlobalId`, **не** считать native GUID и IFC GlobalId одинаковыми строками.
2. **Подготовка G4 (без запуска):** выбрать существующий IFC Publisher Set, одну конкретную 3D View и проверенный IFC Export Translator: `BREP` с соединениями; `Export only geometries which Participate in Collision Detection = OFF`; `Export gross geometry (Export holes separately) = OFF`; видимость всех ожидаемых элементов. Сохранить точные настройки и ожидаемый список GUID/IFC IDs. Создание/изменение Publisher Set в PLN требует отдельного разрешения, сейчас НЕ выполнять.
3. **Только после G3 и явного допуска на файловую публикацию:** через существующий `archicad_bim_documentation.execute_operation` → `PublishPublisherSet` в пустой защищённый каталог. Параметры ровно `{publisherSetName,outputPath,selectedNavigatorItemIds}`; SQLite intent-before-write, при UNKNOWN STOP+READ, не повторять экспорт автоматически.
4. **READBACK:** наличие и SHA256 IFC-файла, фактический набор `IfcRoot.GlobalId`, `IfcWall/IfcSlab/IfcRoof/IfcBeam/IfcColumn/IfcDoor/IfcWindow`, `IfcRelVoidsElement/IfcRelFillsElement`, этажные отношения, материал/свойства; независимый OCC BRep каждого ожидаемого тела, bounding box, объем, оболочки/стыки, отверстия; сравнение с native `GetIFCIdsOfElements` и исходным typed планом. Сверить count IFC с count ожидаемых экспортируемых элементов: если missing/extra — FAIL, не ACCEPTED.
5. **Save/Close/Reopen:** повторить native GUID/IFC ID/тип/story/host/material и геометрию; экспортировать отдельный IFC после reopen, сравнить BRep и IfcDiff. Сохранить старую scratch-копию и квитанции; не использовать Undo для изменений этажей.

**Контраограничения:** IFC BREP не сохраняет нативную параметрическую редактируемость, это QA-артефакт; по Graphisoft BREP-export передаёт геометрию и соединения, но параметры могут быть потеряны. Отдельно проверять BIM-семантику нативным readback. Включённая опция `Export gross geometry` экспортирует стены без вычитания отверстий. `Participate in Collision Detection` фильтр может исключить реальные части здания. Если исходный Publisher Set не существует или выбранная View неполна — `NOT_FOUND_CURRENT_CONFIGURATION`, без создания второго механизма.
