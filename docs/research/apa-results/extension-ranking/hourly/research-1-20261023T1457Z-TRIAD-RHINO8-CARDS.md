**Общее:** Rhino 8 Grasshopper 1 встроен в Rhino, отдельной подписки на перечисленные штатные компоненты нет; нужна действующая лицензия Rhino 8. ## R1457-01 | P0 — Content Cache: Rhino↔Grasshopper с контролем дубликатов
**Операция:** изменить сложную кровлю в Rhino, обновить GH-геометрию без накопления повторных Rhino-объектов. **Контракт:** Content Cache Name/Content/Action → Result; Push/Pull/Bake/Purge; Push отслеживает Rhino object ID, Pull читает Rhino document. **Направление:** GH↔Rhino, НЕ автоматическое AC↔GH. **Источник:** https://www.rhino3d.com/features/grasshopper/content-cache/; https://www.rhino3d.com/docs/grasshopper/Rhino/Content-Cache/; https://discourse.mcneel.com/t/content-cache-updated-guide/181883 (8.8 RC caution). **Ограничение:** Rhino GUID не AC GUID, при изменении структуры дерева объектов/входного ID возможны recreation/duplicates; auto Push — нагрузка. **№2:** нарисовать точный безкодовий GH DAG Query Model Objects→Model Object→Content Cache(Pull/Push)→GH geometry→GH-AC native settings; отдельно определить commit gate и владельца AC Roof. **ГОТОВО:** SOURCE маршрут + будущая отдельная проверка Rhino GUID before/after без native write.

## R1457-02 | P0 — Query Model Objects + Model Object: типизированный выбор Rhino объектов
**Операция:** автоматически выбирать фасадные панели/кровельные поверхности по слоям, материалам и имени, не выбирать вручную по одной. **Контракт:** Query Model Objects (Layer wildcard) → Model Object geometry+attributes. **Направление:** Rhino→GH, при GH pass-through допустима подготовка новых атрибутов. **Источник:** https://www.rhino3d.com/en/docs/guides/grasshopper/object-attributes/; https://www.rhino3d.com/docs/guides/grasshopper/group-sort-filter/. **Ограничение:** Rhino layer/name не native AC classification/GUID; нет подтверждённой обработки изменений без корректной GH recompute. **№2:** пример трёх Rhino групп Roof/Facade/Slabs с read-only фильтрами; сопоставление в typed BIM DAG без записи. **ГОТОВО:** список фильтров и критерии отсутствующих/лишних объектов.

## R1457-03 | P0 — UserText: provenance/owner метки в Rhino
**Операция:** хранить в Rhino object метки APA_SOURCE, APA_OWNER, BUILD_ID, AC_GUID_REFERENCE для сопоставления без второго writer. **Контракт:** GH UserText add/change/remove на Rhino object; Query/Filter по ключам. **Направление:** GH↔Rhino metadata; AC GUID только строковая ссылка. **Источник:** https://www.rhino3d.com/features/grasshopper/usertext/; https://www.rhino3d.com/docs/guides/grasshopper/group-sort-filter/. **Ограничение:** метка не удостоверяет GUID, может устареть, быть дублирована или удалена; AC native identity требует отдельного readback. **№2:** таблица owner/provenance полей с fail-closed правилами при missing/duplicate/stale; без программирования и native write. **ГОТОВО:** протокол идентификации, а не утверждение о синхронизации.

## R1457-04 | P1 — Group/Filter Content: no-code выбор инструментов по данным
**Операция:** выбирать только нужные геометрические классы и проверять площади/назначение до передачи в BIM. **Контракт:** Query Model Objects→Group Content(User Text Building ID)→Match Text/Greater Than/Smaller Than→Intersection Filter→Filter Content. **Направление:** Rhino→GH QA/selection. **Источник:** https://www.rhino3d.com/docs/guides/grasshopper/group-sort-filter/. **Ограничение:** это фильтр, не универсальный автоматический router программ, не СП-проверка; атрибут Area UserText может не совпадать с вычисленной BREP площадью. **№2:** подготовить 3 no-code фильтра: Roof/Facade/Slab; сравнить вычисленную площадь с метаданными. **ГОТОВО:** точная последовательность готовых GH компонентов.

## R1457-05 | P1 — GH Blocks: массовые геометрические повторы
**Операция:** повторяющиеся панели фасада/конструктивные модули в Rhino. **Контракт:** GH создание Block Definition/Block Instance с атрибутами, bake/import. **Направление:** GH→Rhino, НЕ GDL/AC native object. **Источник:** https://www.rhino3d.com/en/features/grasshopper/blocks/. **Ограничение:** связь block instance с AC native колонной/объектом не установлена, экспорт блоков не доказывает GUID/семантику. **№2:** сравнить геометрический повтор Rhino Blocks с существующим Tapir/SceneWriter batch; не вводить второй native writer. **ГОТОВО:** решение KEEP_RHINO_GEOMETRY_ONLY или REJECT.

## R1457-06 | P1 — Import Model transform: контроль единиц внешней геометрии
**Операция:** переносить 3DM/другую CAD геометрию с известными единицами в GH перед сравнением с AC. **Контракт:** Rhino8 GH Import Model → model transform/attributes → Transform Geometry. **Направление:** file→GH, не AC native. **Источник:** https://www.rhino3d.com/en/docs/guides/grasshopper/object-attributes/. **Ограничение:** исправляет единицы внутри Rhino/GH, но не гарантирует одинаковые геопривязку, project origin, story elevation и tolerances AC29. **№2:** разработать read-only таблицу units/origin/axis/Z/tolerance, без установки. **ГОТОВО:** матрица геометрической сопоставимости.
