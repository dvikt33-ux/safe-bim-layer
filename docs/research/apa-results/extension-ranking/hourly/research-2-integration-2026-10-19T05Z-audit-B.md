# APA AC29 05Z — Independent counteraudit B: installation graph and safety

This audit examines nine integration chains separately from audit A (version and license review). No software was executed.

1. All chains reuse the existing APA Router and official JSON interface; the IFC branches reuse the pinned vendor Python runtime. No competing native model writer is needed.
2. Property definition availability must be checked in both directions. The Graphisoft API has these methods, while the checked Tapir snapshot does not.
3. Property status, zero, empty and error are different facts. Filtering unsupported element types must preserve an explicit coverage deficit.
4. Composite skins are nominal attribute data, not the placed solid geometry. They cannot establish structural or regulatory compliance alone.
5. Attribute indices and localized names must not replace stable GUID plus project identity.
6. Classification metadata proves provenance, not whether a building code is legally current.
7. IFC 4D utilities can read task relationships. Mutating scheduling calls are excluded; the existing APA must not become a second scheduling engine.
8. Publisher set names are preflight data, not evidence of a saved PDF. A future output requires a new path, file signature, SHA256 and independent readback.
9. PR165's IFC port counter lacks owners and flow. The existing IfcOpenShell util.system functions provide a narrower reuse path than a new graph implementation.
10. PR173 has a saved and reopened scratch Hotlink batch (69 to 119 GUID, two roots, one native batch call), but no independent final acceptance. PR175 records a later file change with an unproven cause. Do not replay the native write.
11. Rollback may remove only newly produced sidecar reports after approval; no edits to original PLN, APX, main, canonical plan or auditor queue.
12. Verdict: REUSE/ADAPTER for the nine candidates, DEFER for mutating IFC and Publisher LIVE, REJECT a new Hotlink writer. No performance claim.

Evidence level: SOURCE. No new OFFLINE, BUILD, INSTALLED, LIVE or ACCEPTED work.
