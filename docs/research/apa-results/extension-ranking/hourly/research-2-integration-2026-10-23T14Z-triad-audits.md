# APA №2 — 23.10.2026 14Z — два самостоятельных контрааудита (SOURCE, не LIVE)

## Контрааудит A — ложное обещание «no-code JSON = готовая автоматическая трёхсторонняя синхронизация»
**Проверка против первоисточников:** jSwan формирует JSON из GH данных, GH Panel может записать текст; PR74 CLI читает JSON. Однако jSwan 1.2.1 (2020) не имеет доказанной Rhino8 совместимости; GH Panel перезаписывает файл на пересчёте; PR74 authored compiler требует не только координаты, но exact `brief/projectId/path`, CSE material, native stories и native READ-only preflight. `--preflight` не является pure OFFLINE, `--execute` требует отдельного plan hash. GH Panel не выполняет native commit. **Вердикт:** `SOURCE_CANDIDATE_NO_CODE_FILE_HANDOFF`, не `FULL_AUTO_TRIAD`, не `OFFLINE_PASS`. При mismatch, partial JSON или работающем Stream Contents — STOP до dispatch. ## Контрааудит B — нарушение единственного writer и ошибочный native BIM PASS
**Проверка против независимых слоёв:** Graphisoft GH Design может создавать собственные элементы, но их GUID/ID ownership не равен SceneWriter SQLite ledger. `Synchronize=FALSE` не «выполняет preview» — AC Design возвращает Null; для preview нужны обычные GH geometry components. PR74 SceneWriter имеет native CreateWalls/Slabs/Columns/Doors/Windows и typed Roof; Beam adapter не подключён в run_project. Pinned Slab CREATE не принимает Basic/material, хотя SceneWriter журналирует последующий ModifySlabs; наличие журнала не заменяет разрешение. GDL readback условен; MultiPlane/NURBS→same-GUID native Roof NOT_FOUND; GH/3DM/GDL object не равны Roof/Wall/Slab. **Вердикт:** единственный допустимый BUILD-01 native writer = SceneWriter; независимый GUID/BREP/host/material после Save/Open обязателен. Без локальной среды ACCEPTED=0.
