# APA №1 / BUILD-01 — SOURCE 01–12 (G0–G2), 2026-10-22 09:03Z
**Влияние:** подтверждён готовый составной маршрут межэтажной инвентаризации без смены активного окна: официальный Navigator API29 → Tapir GetDatabaseIdFromNavigatorItemId → GetAllElements(databases). G4 приближается к воспроизводимому preflight, но остаётся NOT_RUN. G0 BLOCKED, G3 NOT_AUTHORIZED; здания нет. [BUILD-01 #192](https://github.com/dvikt33-ux/safe-bim-layer/issues/192).

**Метод:** 12 отдельных проверенных контрактных вопросов по реальным первоисточникам; несколько вопросов проверены в одном файле, это не 12 независимых файлов или LIVE. Уровень всех результатов SOURCE. №2 — исполнитель проверки применимости, не разрешение на запись.

**Источники/версии:** [S1 Graphisoft Python API29](https://archicadapi.graphisoft.com/archicadPythonPackage/archicad.releases.ac29.html) (официальная документация AC29, проприетарный интерфейс); [S2 Tapir pinned 1.5.10](https://github.com/dvikt33-ux/safe-bim-layer/blob/f7c37b84b76c040c417ccd58a5543326e50f673a/schemas/tapir-live-1.5.10/tapir-scene-live.json) (архивная схема, не installed); [S3 APA runtime probe](https://github.com/dvikt33-ux/safe-bim-layer/blob/f7c37b84b76c040c417ccd58a5543326e50f673a/scripts/archicad_runtime_version_probe.py); [S4 APA BIM Graph](https://github.com/dvikt33-ux/safe-bim-layer/blob/f7c37b84b76c040c417ccd58a5543326e50f673a/scripts/archicad_bim_graph.py).

01. **G0 / является ли READ_ONLY_VERSION_CHECK доказательством точного build?** S1 GetProductInfo() → tuple(version,build,language); S3 `inventory` возвращает READ_ONLY_VERSION_CHECK даже при `buildMatchesUserScreenshot=false/null`. **Решение:** отдельное fail-closed сравнение build 5101. **Ограничение:** без Windows вызова SOURCE. **№2:** отрицательный сценарий build≠5101 должен давать G0_BLOCKED, не READY.
02. **G0 / доказывает ли версия дополнения идентичность бинарного APX?** S2 GetAddOnVersion возвращает только `version:string`; не путь/хеш. **Решение:** GUI Add-On Manager path + локальный SHA-256 + command-registration. **Ограничение:** реальный путь не получен. **№2:** runtime manifest APX path/hash, port, product build.
03. **G0 / можно ли безопасно закрывать активный проект после GetProjectInfo?** S2 GetProjectInfo возвращает isUntitled/isTeamwork/projectPath/projectName, но не dirty/readOnly. **Решение:** независимый GUI dirty guard и защищённая scratch-копия. **Ограничение:** API не удостоверяет отсутствие несохранённых правок. **№2:** запрет Close/Open без отдельной проверки.
04. **G0 / гарантирован ли индекс этажа 0?** S2 GetStories имеет `firstStory,lastStory,actStory,skipNullFloor,stories`. **Решение:** использовать фактические индексы и floorId, не вычислять арифметически. **Ограничение:** текущий PLN не опрошен. **№2:** вывести таблицу index/floorId/elevation и проверить все bindings.
05. **G4 / есть ли готовое сопоставление Navigator → databaseId?** S2 GetDatabaseIdFromNavigatorItemId v1.1.4 принимает `navigatorItemIds`, возвращает `databases`. **Решение:** использовать вместо нового API-моста. **Ограничение:** доступность локального APX не проверена; нужен контроль соответствия числа ответов. **№2:** read-only probe команды и сопоставление GUID.
06. **G4 / откуда взять Navigator item ID этажей?** S1 GetNavigatorItemTree(NavigatorTreeId), GetStoryNavigatorItems(ids) — штатные AC29. **Решение:** прочитать дерево Project Map и идентификаторы этажей. **Ограничение:** типы NavigatorTreeId и item wrappers должны быть сверены. **№2:** построить таблицу story index → navigator item GUID.
07. **G4 / как избежать неполной инвентаризации активного плана?** S2 GetAllElements v1.0.7 принимает `databases:Databases`, где элемент `{databaseId:...}`; также GetElementsByType принимает databases. **Решение:** передать все проверенные базы этажей, сравнить GUID. **Ограничение:** GetAllElements({}) не равно весь PLN. **№2:** проверка покрытия двух этажей и дубликатов GUID.
08. **G4 / достаточно ли частичного GetDetailsOfElements для BREP?** S2 GetDetailsOfElements v1.5.7 `fields` исключает непрошенные поля из вычисления, включая floorPlanPolygons. **Решение:** быстрый тип/этаж/слой отдельно, полный geometry audit отдельно. **Ограничение:** частичный ответ не доказательство полной геометрии. **№2:** два явных профиля чтения.
09. **G2 / одинакова ли Z-семантика Wall и Slab?** S2 CreateWalls v1.4.0: `zCoordinate` относительно этажа при `floorIndex`; без floorIndex абсолютная Z. **Решение:** floor-relative Wall z=0, сравнить readback с elevation. **Ограничение:** поведение модифицированного APX неизвестно. **№2:** не вычитать story elevation дважды.
10. **G2 / абсолютен ли уровень Slab?** S2 CreateSlabs v1.0.3: `level` Z reference line, `floorIndex` optional; [native plan](https://github.com/dvikt33-ux/safe-bim-layer/blob/f7c37b84b76c040c417ccd58a5543326e50f673a/scripts/archicad_authored_native_plan.py) передаёт `level=story.level` и маркирует PROJECT_ABSOLUTE. **Решение:** не унифицировать Wall/Slab offsets. **Ограничение:** только pinned schema/source. **№2:** контроль абсолютного zCoordinate и relative level.
11. **G2 / есть ли обязательная проверка размещения окна в host?** S2 CreateWindows/CreateDoors v1.4.0: `ownerWallId,centerOffset` обязательны, width/height опциональны, `libraryPartName` поддерживается схемой. **Решение:** host GUID, длина стены, высота, effective library part и реальные размеры после CREATE. **Ограничение:** схема не задаёт max centerOffset. **№2:** проверить фактическую библиотечную ширину до G3.
12. **G1 / не продублируем ли уже готовую проверку host-fit?** S4 `_hosted_fit_errors` уже проверяет offset±width/2, sill+height и прямую стену; для curved/неявных Favorite dimensions пропускает. **Решение:** переиспользовать существующий валидатор, закрыть только пробелы данными. **Ограничение:** не считать этот пропуск ошибкой установки. **№2:** пометить curved/Favorite hosts как NEEDS_NATIVE_PREFLIGHT, не писать второй валидатор.
