# APA №1 — дополнительные барьеры против потерь AC29 / Rhino8 / Grasshopper
Дата 2026-10-23. Статус SOURCE_ONLY + ENGINEERING_PROPOSAL. BUILD-01 issue #192. Новых LIVE/PASS нет.

## P0 — до любой нативной записи
1. FAIL_CLOSED WRONG_PROJECT: использовать один контролируемый экземпляр Archicad и scratch PLN, зафиксировать номер порта и версию+сборку GetProductInfo, имя/путь проекта и активный этаж независимо; несовпадение = STOP. Официальный Python API ACConnection.connect(port) подключается к порту, GetProductInfo возвращает (version, build, lang), но НЕ подтверждает путь PLN. Источник: https://archicadapi.graphisoft.com/archicadPythonPackage/archicad.html.
2. FAIL_CLOSED WRITE_SCOPE: операции DELETE, PURGE, RECREATE, массовый CREATE и редактирование Embedded Library по умолчанию запрещены. Разрешить только конкретную операцию, выбранные GUID и один механизм записи — GH Live Connection либо существующий SceneWriter; не обе записи одновременно. Это предлагаемая политика эксплуатации APA, а не готовая универсальная функция платформ.
3. NO_BLIND_RETRY: после тайм-аута сначала READBACK и сверка GUID/количества; не повторять CREATE, пока неизвестен результат первой попытки. Не заявлять наличие автоматического idempotency engine.
4. PROVENANCE: в исторической документации GH/Teamwork существуют свойства Grasshopper Source Definition и Last update from Grasshopper, а SEO при delete/recreate теряет связь. Проверить их наличие и поведение именно AC29. Свойство источника НЕ заменяет реальный GUID. Источник: https://community.graphisoft.com/t5/Teamwork-BIMcloud/Grasshopper-ARCHICAD-Live-connection-Teamwork/ta-p/303680.
5. UNITS CONTRACT: JSON API AC29 возвращает SI (m, m2, m3, rad) независимо от настроек пользовательского интерфейса, Rhino имеет независимые units и absolute tolerance. Перед записью — контрольный метровый отрезок, этажная отметка, bbox и преобразование координат. Источники: https://archicadapi.graphisoft.com/JSONInterfaceDocumentation/ ; https://docs.mcneel.com/rhino/8mac/help/en-us/documentproperties/units.htm.

## P1 — многоуровневая проверка
6. THREE_INDEPENDENT_READBACKS: а) API GUID + тип + координаты + свойства + количество; б) Archicad29 Model Compare 3D added/modified/deleted; в) Interactive Schedule с количеством по типу, материалами, этажами и свойствами. Ограничения: Model Compare игнорирует 2D, интерактивная ведомость не доказывает сохранение GUID. Источники: https://help.graphisoft.com/AC/29/INT/_AC29_Help/081_ModelCompare/081_ModelCompare-1.htm ; https://help.graphisoft.com/AC/29/INT/_AC29_Help/055_InteractiveSchedule/055_InteractiveSchedule-1.htm.
7. QA VISIBILITY: до проверки collision и Physical Model Quality включать заданную комбинацию видимых слоёв и проверять группы/допуски. Обе штатные процедуры учитывают только видимые элементы; поэтому PASS при скрытых слоях ложный. У Collisions касание не является столкновением, SEO/Priority-Based Connections уже разрешены; участие строительных материалов в проверке может быть выключено. Источники: https://help.graphisoft.com/AC/29/INT/_AC29_Help/080_Collaboration/080_Collaboration-64.htm ; https://help.graphisoft.com/AC/29/INT/_AC29_Help/092_ModelCheck/092_ModelCheck-2.htm.
8. RHINO GEOMETRY GATE: Check, SelBadObjects, SelOpenPolysrf и SelNonManifold для ожидаемых solids, плюс координаты и единицы. Ошибка = STOP до передачи в Archicad, не автоматическое удаление плохих объектов. Источники: https://docs.mcneel.com/rhino/8/help/en-us/commands/check.htm ; https://docs.mcneel.com/rhino/8/help/en-us/commands/selection_commands.htm.
9. LIBRARY QUARANTINE & VERSIONS: общие элементы брать из устойчивой Linked Library; использовать PLA с контролем состава загружаемых элементов; архив, сделанный после исчезновения объектов, их не возвращает. Заморозить номера версий: Archicad29 build5101, hash локального Tapir1.5.10, версии GH/Connection/Rhino8. Rhino IncrementalSave создаёт версионный 3DM; также сохранять GH файл, PLN/PLA в изолированной копии. Источники: https://help.graphisoft.com/AC/29/RUS/_AC29_Help/020_Configuration/020_Configuration-30.htm ; https://help.graphisoft.com/AC/29/INT/_AC29_Help/020_Configuration/020_Configuration-47.htm ; https://docs.mcneel.com/rhino/8/help/en-us/commands/save.htm.

## Безопасная последовательность
G0 check instance/port/project/versions -> READ baseline count/GUID/attributes/bbox -> validate units/coordinates and Rhino solids -> authorize one writer one scoped operation -> GH Synchronize FALSE during edit -> commit one controlled sync -> independent readback API + Model Compare + Schedule + Library Manager + collision QA with visible layers -> scratch Save/Close/Reopen -> ACCEPT or STOP/restore prior copy.
GH Boolean Toggle с FALSE не следует считать транзакционным механизмом или независимым доказательством правильного состава элементов; см. https://community.graphisoft.com/t5/Modeling/Grasshopper-ARCHICAD-Live-connection/ta-p/303564.

## Два контрааудита
A SOURCE/VERSION. Источники производители Graphisoft/McNeel; документ Teamwork исторический (2017/2021), не подтверждает фактическую локальную конфигурацию AC29; фактические команды Tapir 1.5.10 не проверялись. Никто не выполнял LIVE.
B ENGINEERING. Model Compare недостаточен для identity, ведомость недостаточна для отношений/SEO; скрытые слои создают неполный QA; Rhino Check не гарантирует BIM семантику; PLA не восстановит то, чего в момент архивации не было. Автоматическое переключение writer/глобальный rollback не подтверждены.
