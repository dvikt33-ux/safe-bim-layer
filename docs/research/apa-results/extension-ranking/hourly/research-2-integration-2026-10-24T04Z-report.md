## 1. Новая P0-дельта (три доказанных ограничения)

**P0-I04-01 — официальная 3DM-связь хранит Rhino ID, но не превращает Rhino в нативные стены/кровли.** В документации **Archicad 29** «Open or Merge Rhino Model» прямо сказано: Rhino импортируется как **non-editable GDL objects**; каждый Rhino element становится отдельным **.gsm** в Embedded Library. Свойства группы **Rhino** хранят исходные **Rhino Layer и Rhino original ID**. Это готовый **provenance crosswalk** Rhino Object ID→Archicad импортированный Object, без нового синхронизатора. Однако этот ID — **не** Archicad GUID и **не** BIM-тип Wall/Slab/Roof. Сохранение native GUID при обновлении Hotlink не обещано. Источник: https://help.graphisoft.com/AC/29/INT/_AC29_Help/120_Interoperability/120_Interoperability-41.htm (строки 2–7, 125–127, 155–164).

**P0-I04-02 — Rhino Hotlink имеет скрытые геометрические/библиотечные побочные эффекты.** AC29 поддерживает File→External Content→Place Hotlink→*.3dm; hotlink размещается на **активном этаже**; сегментацию кривых поверхностей **после размещения изменить нельзя**. При импорте скрытые в Rhino объекты по умолчанию исключены; импорт цветов может создать новые Archicad Surfaces, слоёв — новые Archicad Layers. Модуль редактируется как единое целое. Встроенные библиотечные части, зависящие от Hotlink, могут быть удалены после удаления последнего экземпляра (видно после повторного открытия). Hotlink Relink **очищает Undo queue**. Это допустимый путь **reference-only** для сложной формы, но не ACCEPTED native BIM. Источники: https://help.graphisoft.com/AC/29/INT/_AC29_Help/120_Interoperability/120_Interoperability-41.htm; https://help.graphisoft.com/AC/29/INT/_AC29_Help/120_Interoperability/120_Interoperability-43.htm; https://help.graphisoft.com/AC/29/INT/_AC29_Help/080_Collaboration/080_Collaboration-56.htm; https://help.graphisoft.com/AC/29/INT/_AC29_Help/080_Collaboration/080_Collaboration-60.htm.

**P0-I04-03 — два вида подрезки кровлей не эквивалентны.** В AC29 **Crop to Single-plane Roof** неассоциативен: изменение Roof не пересчитывает автоматически статическую подрезку; полная поперечная подрезка может **разделить одну Wall на две**; для Slab отмена только обычным Undo. В отличие от него **Trim to Roof/Shell** / SEO создают ассоциативные связи, но требуют сохранения связей и проверки результирующего BREP. В существующем PR74 есть ограниченный `nativeRoofJunctions`: **ровно одна** Roof, верхние Wall, `GetSolidElementLinks` и `CreateSolidElementLinks` (SubtractionUpwards), явный допуск и журнал; отверстия Roof отвергаются. Это **не** MultiPlane и не общий GH→AC join. Источники: https://help.graphisoft.com/AC/29/INT/_AC29_Help/040_ElementsVB/040_ElementsVB-88.htm; https://help.graphisoft.com/AC/29/INT/_AC29_Help/040_ElementsVB/040_ElementsVB-269.htm; https://github.com/dvikt33-ux/safe-bim-layer/blob/5a3a9201a715a5528c93bed4a5318e2acb32eea7/scripts/archicad_authored_extension.py#L243-L335.

## 3. Два принципиально разных режима, которые нельзя смешивать

**Режим A — AUTHORING (BUILD-01):** Rhino 8/Grasshopper → структурированные параметры/контуры в ограниченной форме `apa-authored-project/1` → **существующий** PR74 → BIM Graph → SceneWriter/SQLite → Tapir → нативный AC29. AC→GH/Rhino после операции — **отдельный readback**, а не автоматически гарантированное обновление. Один writer для APA-owned элементов. **Предпочтителен для G1–G4**.

**Режим B — REFERENCE (сложная Rhino BREP):** Rhino 8 `.3dm` → AC29 штатный Hotlink → импортированные GDL Objects с исходными Rhino ID в свойствах → обновление Hotlink по команде. Дает визуально/геометрически связанную модель, **не** нативные Roof/Wall/Slab и **не** GUID-preserving roundtrip. Нельзя засчитывать в G3/G4 BUILD-01 как native BIM. В этом исследовании никаких Hotlink не размещалось.

**Режим C — официальный GH-owned native writer:** GH–AC29 Live Connection умеет создавать поддержанные native элементы, включая Single-plane Roof; но запись тех же элементов одновременно через GH и APA создает **конкурирующих writers**. Возможна только раздельная ownership-модель (GH-owned ≠ APA-owned), с отдельной приемкой; общий журнал/rollback/merge между ними **NOT_FOUND**. В BUILD-01 прямую GH→AC запись не включать без отдельного разрешения и G0.

## 5. Контроль геометрии, норм и опасных операций

1. **Rhino imported ID** в Archicad свойстве служит для provenance, но при обновлении Hotlink проверить заново `RhinoID→AC Object GUID`; не объявлять стабильность без двух readback.
2. **Hotlink Update** меняет зависимые объекты; `Relink` может очистить Undo; удаление модуля способно удалить Embedded Library Parts. Прежде чем принять, нужен Save/Open + inventory, даже для reference.
3. **Crop to Single-plane Roof** — неассоциативен и может расщепить Wall: **запретить** в identity-preserving автоматической ветке. Предпочесть явно квалифицированный ассоциативный Trim/SEO; PR74 реализует только ограниченный SubtractionUpwards.
4. **Нормативная проверка** GH — численные правила с редакцией СП, исходными данными, допусками; не сертифицированная экспертиза. Площадь 3D границ Zone не считать площадью пола.
5. **Материал Rhino Surface** не равен **Archicad Building Material/Composite**; импорт цвета создаёт Surface и не доказывает конструктивный состав. Сравнивать по отдельным полям.
