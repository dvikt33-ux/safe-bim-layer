## P0: найден ранее недооценённый готовый APA-owned Beam route

**Различать три уровня:**
1. **Authored PR74** `compile_authored_intent`: дополнительные `nativeComponents` допускают `CreateColumns/CreateDoors/CreateWindows/CreateWalls/CreateRoofs`, но **не** `CreateBeams`. Универсальный `Rhino→GH→authored JSON→Beam` через этот вход остаётся **NOT_FOUND**. См. [project_accelerator.py](https://github.com/dvikt33-ux/safe-bim-layer/blob/5a3a9201a715a5528c93bed4a5318e2acb32eea7/scripts/archicad_project_accelerator.py#L280).
2. **Существующий отдельный connected CLI** `archicad_connected_components.py`: `adapters(['beam'])` отображает `beam→CreateBeams`; `bind_plan` валидирует typed graph через существующий каталог; `main` принимает `--source`, `--intent`, `--mode offline|preflight|execute`, `--output`. `SceneWriter(..., adapters=adapters(enabled))` использует **тот же SQLite/SceneWriter**, не новый writer. [connected_components.py](https://github.com/dvikt33-ux/safe-bim-layer/blob/5a3a9201a715a5528c93bed4a5318e2acb32eea7/scripts/archicad_connected_components.py#L288), [CLI](https://github.com/dvikt33-ux/safe-bim-layer/blob/5a3a9201a715a5528c93bed4a5318e2acb32eea7/scripts/archicad_connected_components.py#L522).
3. **Нативный typed Beam adapter** требует точные поля прямой Basic-балки: `begCoordinate/endCoordinate/zCoordinate/floorIndex/offset/slantAngle/isSlanted/profileAngle/arcAngle/verticalCurveHeight/width/height/anchorPoint/circleBased/isWidthAndHeightLinked/buildingMaterialId`; `anchorPoint=Center`, `circleBased=false`, `isWidthAndHeightLinked=false`, `arcAngle=0`, `verticalCurveHeight=0`. После записи проверяются тип Beam, этаж, ось, уровень, материал, профиль, дочерние BeamSegment GUID, родительские связи и закрытые BREP. [NativeAdapter](https://github.com/dvikt33-ux/safe-bim-layer/blob/5a3a9201a715a5528c93bed4a5318e2acb32eea7/scripts/archicad_connected_components.py#L98), [verify](https://github.com/dvikt33-ux/safe-bim-layer/blob/5a3a9201a715a5528c93bed4a5318e2acb32eea7/scripts/archicad_connected_components.py#L158).

**Инженерное решение:** для балок, принадлежащих APA, есть **готовый двухэтапный маршрут**, не требующий второго writer: (A) уже подтверждённая authored-модель/receipt; (B) отдельное typed `CreateBeams` через существующий connected CLI. Это **SOURCE-наличие маршрута**, не готовая однопроходная сборка и не новый LIVE PASS. Предусловие CLI: локальный accepted `--source` с `preflight/created/inventory`; без него не запускать. `--intent` — уже структурированный typed JSON, а не произвольный BREP Rhino. Точная версия и регистрация `CreateBeams` в установленном Tapir 1.5.10 остаются G0-проверкой.

**Дополнительная граница:** `archicad_native_beam_details.prepare_beam` уже конвертирует **только** два source-bound прямоугольных элемента `c4/c5` в нативный Beam и требует provenance, контакт и отдельную проверку торца. Это НЕ универсальный GH Curve→Beam адаптер. [beam_details.py](https://github.com/dvikt33-ux/safe-bim-layer/blob/5a3a9201a715a5528c93bed4a5318e2acb32eea7/scripts/archicad_native_beam_details.py#L16).

## P0: Rhino8 GrasshopperPlayer — реальный запуск GH, но не синхронизатор

Официальный McNeel Rhino 8: `-GrasshopperPlayer` запускает **существующий** `.gh/.ghx` из Rhino Command Line без открытия редактора; путь может быть абсолютным, с переменными окружения или найденным через Search Paths. Для воспроизводимости использовать **только полный путь + SHA**: одноимённый файл в каталоге `.3dm` или Search Paths может дать неверное определение. [McNeel Help](https://docs.mcneel.com/rhino/8/help/en-us/commands/grasshopper.htm).

`-Grasshopper Solver Disable/Enable` управляет вычислением GH, но **не** является commit/rollback, не подтверждает отсутствие компонентов GH Design/Content Cache Push, не доказывает завершение внешней записи. `-GrasshopperPluginList` сообщает использованные плагины загруженного определения, но не доказывает наличие подходящей установленной версии Graphisoft Connection. Никаких команд на машине не выполнялось.

**Готовый G0 inventory без исполнения:** для каждой существующей `.gh/.ghx`: абсолютный путь, SHA256, имя активного `.3dm` и его SHA, Rhino SR, единицы, GH plugin list, имена входов/выходов, наличие GH Design/Content Cache/скриптов с side effects, owner, требуемый native target PLN/port. При неизвестном определении или возможном write-side-effect — STOP. Отдельный GHPlayer вызов возможен лишь после допуска.

**Обязательная последовательность для каждого разрешённого будущего исполнения:** G0 immutable `.gh/.3dm/PLN` + активный порт/APX/Tapir/библиотеки/этажи → G1 read-only authored preflight и typed DAG/hash → G2 каталог+owner+source receipt/typed adapter → G3 только отдельный письменный допуск на конкретный scratch PLN/port/hash, один SceneWriter dispatch → G4 GuardedSave, реальное Close/Open, сравнение native GUID/type/material/BREP/host и IFC с независимым export translator → G5 другое здание на другой копии. При timeout/unknown outcome НЕ повторять CREATE; только read-only reconciliation.

**Двусторонность и удаление:** Rhino→GH вычисление, GH→AC native Design, AC→GH read-only reference и AC .3dm Hotlink — разные односторонние/ограниченно обратные маршруты. Ни один из них не обеспечивает одновременный AC↔GH↔Rhino GUID-preserving transaction. При смене Beam↔Column, удалении source, Hotlink re-link, GDL library removal, непреднамеренном новом GUID, цикле GH Design↔Content Cache — STOP. Source-of-truth/owner назначается по элементу, не по приложению в целом. Нормативные проверки площадей/ширин/высот/эвакуации/доступности выполняются только по подтверждённым native значениям и применимым СП; числовой фильтр не заменяет экспертизу.
