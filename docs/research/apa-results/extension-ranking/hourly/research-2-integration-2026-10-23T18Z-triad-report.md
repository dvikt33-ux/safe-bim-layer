# APA №2 — TRIAD / BUILD-01 — 2026-10-23 18Z

**Вклад в BUILD-01 G1/G2:** доказана критическая неодинаковость высотных координат **Wall vs Slab** в pinned Tapir 1.5.10: `CreateWalls.floorIndex` делает `zCoordinate` смещением от домашнего этажа, тогда как `CreateSlabs.level` в authored PR74 — абсолютная проектная Z. При передаче одного globalZ из Grasshopper второй этаж стены может подняться дважды. **Второй найденный риск:** `ModifySlabs.polygonOutline` без `holes` удаляет прежние отверстия. Оба — SOURCE_VERIFIED, не INSTALLED/LIVE.

## Точное воспроизводимое решение без нового writer/router

1. **Источник:** Rhino 8 — геометрия/контуры/параметры; Grasshopper — зависимость, тип элемента, storyId, GUID-source key. Работать в метрах и в единой XY-системе; сохранять исходный Rhino/GH документ и его SHA. Перед сериализацией преобразовать координаты **по типу команды**, а не глобальным преобразованием всех Z.
2. **Безкодовый контракт GH→APA:** jSwan MIT `Serialize JSON` с явно заданными `x/y`, корректными вложенными arrays/objects, без null для typed необязательных полей. Сформировать `apa-authored-project/1`, `brief`, `cseCandidate`, `layout`, `storyHeights`, `floorPlans`, `nativeComponents`; сохранить staging JSON. Rhino8 совместимость конкретной jSwan binary ещё не проверена. Не утверждать, что одна геометрия Rhino автоматически превращается в валидный authored intent.
3. **Привязка этажей:** получить реальные `GetStories` index/floorId/name/level; не угадывать. Для стены на втором этаже +3.000: `floorIndex=1,zCoordinate=0`; для перекрытия второго этажа: `floorIndex=1,level=3.000`. Это иллюстрация семантики, не проектные отметки BUILD-01. `SetStories` — отдельный WRITE, не запускать в G0/G1.
4. **Один компилятор:** `compile_authored_intent` PR74 → существующий BIM Graph DAG, `sourcePlanHash`, SQLite SceneWriter. Приоритет G1 — прочитать schema, проверить разрешённую scratch PLN, получить read-only preflight; `run_project` authored не принимает автономный offline как доказательство. Прямая GH–AC native-запись для APA-owned элементов должна быть выключена: два writer создадут конкурирующие GUID/журналы.
5. **Создание после отдельного G3-допуска:** Walls, Slabs, hosted Doors/Windows, Columns, typed single-plane Roof. Beams и MultiPlane Roof имеют документированные нативные функции, но существующий authored путь ограничен; не приравнивать наличие схемы к полной интеграции. Для Slab материала: `CreateSlabs` не принимает `buildingMaterialId/structureType`; требуется квалифицированный Favorite или отдельно разрешённый `ModifySlabs`.
6. **Модификация Slab:** если меняется только отверстие, `ModifySlabs.holes` допускается без `polygonOutline`; если меняется контур, обязательно повторно передать все требуемые отверстия. Проверить hole count/geometry в `GetDetailsOfElements` до/после. Это не native Opening с отдельным GUID.
7. **Завершение и контроль:** зафиксировать план и его SHA, выключить GH recompute (официальный Rhino8 `-Grasshopper Solver Disable`) и GH–AC `Synchronize` для независимых GH-generated элементов, провести native READ inventory, выполнить только одобренный SceneWriter, проверить GUID/тип/story/host/material/геометрию, GuardedSave→Close→Open→повторный readback. GH `Synchronize=false` возвращает Null, а не квитанцию APA; статус ранее созданных GH-элементов отдельно сверять по Archicad.
8. **Конфликт, удаление, rollback:** если AC изменён вручную после GH snapshot или есть другой writer, `CONFLICT_STOP`, READ reconciliation, никаких автоматических Delete/Create. Изменение структуры этажей очищает Archicad Undo queue; откат должен опираться на защищённую PLN-копию, не Undo. Ни один сценарий G3/G4/G5 не запускался.

## Официальные версии, лицензии, направления

- [Graphisoft GH–AC29 Live Connection](https://www.graphisoft.com/en-de/downloads/add-ons/rhino-grasshopper/): **build 3000**, опубликован **01.10.2025**, Windows и Rhino 7/8; бесплатный add-on, лицензии Rhino/Archicad отдельно. Совместимость конкретно с AC29 build5101 на этом ПК **INSTALLED_NOT_VERIFIED**.
- [Graphisoft GH–AC29 User Guide](https://help.graphisoft.com/AC/29/INT/GC.pdf): `Synchronize=true` создаёт/обновляет GH-generated native элементы, `false` возвращает Null; `Deconstruct` + `Send Changes` — ограниченный AC→GH read. MultiPlane Roof не обрабатывается `Deconstruct Roof`. Это **не симметричная трёхсторонняя синхронизация**.
- [Rhino8 Grasshopper](https://docs.mcneel.com/rhino/8/help/en-us/commands/grasshopper.htm): штатные `-Grasshopper Solver Enable/Disable`, без дополнительного плагина; Rhino лицензируется отдельно. [jSwan](https://github.com/andrewheumann/jSwan) MIT, сериализует JSON; точная совместимость установленного Rhino8/jSwan не проверена. [Tapir](https://github.com/ENZYME-APD/tapir-archicad-automation) MIT, закреплённый snapshot provider 1.5.10 = **SOURCE**, не текущий binary/schema.
- Схема Tapir 1.5.10: [immutable pinned JSON](https://github.com/dvikt33-ux/safe-bim-layer/blob/f7c37b84b76c040c417ccd58a5543326e50f673a/schemas/tapir-live-1.5.10/tapir-scene-live.json). Исполнитель: [PR74 compiler](https://github.com/dvikt33-ux/safe-bim-layer/blob/f7c37b84b76c040c417ccd58a5543326e50f673a/scripts/archicad_project_accelerator.py), [native plan](https://github.com/dvikt33-ux/safe-bim-layer/blob/f7c37b84b76c040c417ccd58a5543326e50f673a/scripts/archicad_authored_native_plan.py), [SceneWriter](https://github.com/dvikt33-ux/safe-bim-layer/blob/f7c37b84b76c040c417ccd58a5543326e50f673a/scripts/archicad_scene_run.py), [building shell](https://github.com/dvikt33-ux/safe-bim-layer/blob/f7c37b84b76c040c417ccd58a5543326e50f673a/scripts/archicad_building_shell.py), [semantic brief](https://github.com/dvikt33-ux/safe-bim-layer/blob/f7c37b84b76c040c417ccd58a5543326e50f673a/scripts/archicad_semantic_brief.py).
