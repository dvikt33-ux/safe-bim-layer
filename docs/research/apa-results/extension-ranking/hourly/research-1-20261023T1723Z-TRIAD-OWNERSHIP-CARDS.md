## C1723-01 [P0] Безопасность GH-created Embedded Library Parts
**Операция:** параметрический нестандартный объект Rhino/GH→AC без написания GDL. **Готовое:** Object Settings → Create New Library Part (Geometry/Object Name), встроенная Embedded Library. **Официальный AC29 контракт:** при изменении GH геометрии Library Part обновляется; при удалении GH Object Settings или переключении на Use existing Library Part сгенерированная Library Part удаляется, размещённые экземпляры становятся Missing Objects. **Направление:** GH→AC, без доказанной обратной записи. **Источник:** https://help.graphisoft.com/AC/29/INT/GC.pdf, раздел Create New Library Part, стр.45. **Ограничение:** операция меняет проектную библиотеку, не только 3D-геометрию; нельзя использовать как безопасную «временную подложку». **№2:** оформить fail-closed policy: в BUILD-01 запрещено удалять/переключать GH Object Settings, пока не доказана независимая сохранность всех библиотечных ссылок; добавить library inventory и missing object count к Save/Open. **ГОТОВО:** 0 missing objects, стабильная библиотечная identity после разрешённого reopen; сейчас NOT_RUN.

## C1723-02 [P0] One-active-GH-document + source pairing
**Операция:** избежать отправки изменений в неверную GH definition/PLN. **Готовое:** File → Connect Document to Archicad и повторное соединение PLN с GH origin definition; GH-generated native элементы остаются в PLN даже без .gh. **Направление:** выбор GH→AC соединения и восстановление пары, не полноценный 3-way sync. **Источник:** https://help.graphisoft.com/AC/29/INT/GC.pdf, File Handling, стр.84. **Ограничение:** только одна GH definition связана с AC в данный момент; существование двух .gh файлов не означает одновременную синхронизацию. **№2:** read-only preflight: exact .pln identity/path, GH file path/hash, connected GH document name, AC instance, link status; если неизвестно — STOP. **ГОТОВО:** доказана корректная пара и стабильная identity после reopen; сейчас BLOCKED_RUNTIME.

## C1723-03 [P0] GH parameter precedence / ручные изменения AC
**Операция:** менять материал/параметры без циклического перезаписывания. **Готовое:** штатное Lock/Unlock GH Elements и правила precedence AC29: GH-controlled parameter после возобновления соединения снова контролируется GH, AC-only parameter может сохраняться. **Направление:** GH→AC на управляемых полях; AC→GH ограничено параметрами/Send Changes, не универсальный same-GUID writer. **Источник:** https://help.graphisoft.com/AC/29/INT/GC.pdf, Important Notes. **Ограничение:** один элемент может иметь разных владельцев разных параметров, даже при одном writer. **№2:** полевая матрица owner/parameter: geometry, story, material, classification, library, host; для APA-owned элементов GH Sync запрещён. **ГОТОВО:** контрольное изменение не откатывает чужие поля, GUID/SEO сохранены; NOT_RUN.

## C1723-04 [P0] Teamwork reservation → duplicates/stale/SEO
**Операция:** предотвращать размножение native элементов при конфликте доступа. **Готовое:** штатное Teamwork reservation; Graphisoft исторически документирует, что чужое резервирование может вызвать duplicate, отсутствие резерва — игнорирование update/delete, delete/recreate — потерю SEO/GUID. **Направление:** управление правами в AC, не sync engine. **Источник:** https://community.graphisoft.com/t5/Teamwork-BIMcloud/Grasshopper-ARCHICAD-Live-connection-Teamwork/ta-p/303680 (2017, ред.2021). **Ограничение:** исторический Teamwork контракт; для локальной solo PLN не переносить как доказанный баг AC29. **№2:** добавить read-only gate: solo vs Teamwork, reservation status, 1 source element→1 target GUID, before/after counts, SEO; при Teamwork неопределённости BLOCKED. **ГОТОВО:** без дубликатов, orphan и SEO loss на санкционированной копии; NOT_RUN.

## C1723-05 [P0] Synchronize False не равен DELETE; приостановка модальными окнами
**Операция:** безопасно останавливать GH запись и не считать модель автоматически очищенной. **Готовое:** Synchronize Boolean input, GH Stream Filter/Toggle для контролируемого пустого input (исторический workaround); официальный AC29 guide подтверждает, что открытое диалоговое окно AC приостанавливает соединение. **Источники:** https://community.graphisoft.com/t5/Parametric-design/Synchronize-Bug/m-p/292446/highlight/true (2020), https://help.graphisoft.com/AC/29/INT/GC.pdf (AC29). **Направление:** GH→AC gate, НЕ транзакция и НЕ автоматический rollback. **Ограничение:** FALSE исторически оставляет старые native элементы; null-input workaround может УДАЛЯТЬ их, потому его нельзя применять на пользовательской PLN. **№2:** разделить PAUSE, DISCONNECT, DELETE, REBUILD, UNDO как разные операции; описать безкодовую схему статусов и запрет destructive null без разрешения. **ГОТОВО:** stale element count=0 при явно санкционированном сценарии удаления; NOT_RUN.

## C1723-06 [P1] GH source provenance / копирование отвязывает элементы
**Операция:** выяснять происхождение native элементов и отличать живую связь от копии. **Готовое:** исторически GH Source Definition и Last update from Grasshopper; официальный AC29 guide подтверждает, что copy-paste GH-created native элемента создаёт копию, не связанную с GH-кодом. **Источники:** https://community.graphisoft.com/t5/Teamwork-BIMcloud/Grasshopper-ARCHICAD-Live-connection-Teamwork/ta-p/303680 (historical), https://help.graphisoft.com/AC/29/INT/GC.pdf (AC29). **Ограничение:** метка происхождения НЕ Archicad GUID и не подтверждает живую связь; свойства на AC29 ещё не инвентаризированы. **№2:** source-only inventory: GH-linked vs detached copies vs APA-owned, with GUID+element type+source file; не удалять копии без explicit ownership. **ГОТОВО:** однозначное ownership mapping и ноль конфликтов; NOT_RUN.

## C1723-07 [P0] GDL GLOB_INTGUID — read-only native identity
**Операция:** запретить ложную «синхронизацию GUID» через пользовательский ID или GDL UserText. **Готовое:** официальный GDL GLOB_INTGUID доступен как внутренний, не контролируемый пользователем идентификатор; GLOB_ID — пользовательский ID. **Источник:** https://help.graphisoft.com/AC/29/INT/GDL.pdf, GDL Reference Guide 29, General element parameters. **Направление:** AC read-only identity evidence; не механизм записи. **Ограничение:** GDL-скрипт не может назначить требуемый native GUID при пересоздании. **№2:** критерий: сравнение настоящего GUID через GetDetailsOfElements/доступный native readback, а не ID, UserText, Rhino Object ID или IFC GlobalId. **ГОТОВО:** GUID сохраняется при update, host/SEO и BREP совпадают; NOT_RUN.
