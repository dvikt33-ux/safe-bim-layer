## Воспроизводимый SOURCE-маршрут полигональных отверстий
Rhino8: planar outer/inner contours → GH: closed curves, разложить каждую вершину на x/y в метрах, построить список объектов `{x,y}` → jSwan Serialize Keys and Values: вложенные arrays и objects, явные lower-case keys → `floorPlans` по каждому storyId → неизменяемый JSON staging + SHA → PR74 `compile_authored_intent` (READ GetProjectInfo/GetStories/GetAttributesByType) → существующий BIM Graph DAG → SceneWriter/SQLite (только после отдельного G3) → Tapir CreateSlabs/ModifySlabs → GetDetailsOfElements + независимая геометрия → GuardedSave/Close/Open/re-read. Ни одна локальная ступень не запускалась.

Иллюстративный фрагмент `floorPlans`, **не полный компилируемый проект**, storyId должны точно совпасть с `brief.stories`:
```json
{
  "floorPlans": {
    "story-0": {
      "polygonCoordinates": [{"x":0,"y":0},{"x":12,"y":0},{"x":12,"y":9},{"x":0,"y":9}],
      "holes": [{"polygonCoordinates":[{"x":5,"y":3},{"x":5,"y":5},{"x":7,"y":5},{"x":7,"y":3}]}]
    },
    "story-1": {
      "polygonCoordinates": [{"x":0,"y":0},{"x":12,"y":0},{"x":12,"y":9},{"x":0,"y":9}],
      "holes": []
    }
  }
}
```
Требуются реальная геометрия bearingLines/rooms, привязка этажей и проверенный материал; образец не выдаётся за schema pass. Дополнительный риск: `floorPlans` проверяется по всем этажам и wall lines могут пересекать пустоту — fail-closed.
