# Дополнительное независимое исследование APA29 — 18.10.2026

## Проверенный первоисточник
[Официальные релизы Tapir](https://github.com/ENZYME-APD/tapir-archicad-automation/releases) и [официальный репозиторий](https://github.com/ENZYME-APD/tapir-archicad-automation).

1. В release notes **1.5.6** прямо указаны `GetGroupsOfElements`, `GetElementsOfGroups`, `Get/SetSuspendGroupsMode` (PR #475). Следовательно, эти команды **не являются новыми в 1.7.x**. Это доказательство существования в исходной версии, **не** доказательство фактической регистрации в локальном Tapir 1.5.10.
2. В **1.5.6** также указаны MEP-команды create/modify/connect/query (PR #473). Это не подтверждает наличие нужного setter двухпортового перехода, корректных портов и сквозной приёмки APA.
3. В **1.6.0** отмечено `SaveProjectAsArchive` (PR #671) и изменение `SaveProject` для сохранения из любого окна (PR #683). Поэтому нельзя переносить контракт 1.6.0 на локальную 1.5.10 и нельзя считать `SaveProject` безопасным Save As.
4. Официальный README показывает отдельную сборку Add-On под **Archicad 29 Windows**; это доказательство наличия дистрибутива, не установки/приёмки на ноутбуке.

## Исправление исследовательской логики
- Группы: сначала проверить **реально отсутствующие** команды, затем сравнить с PR #159/#162; не создавать второй исполнитель.
- MEP: отделить наличие общего набора команд от конкретной возможности двухпортового перехода.
- Публикация: изолировать публикацию и сохранение, не вызывать SaveProject на оригинальном PLN.
- Multiply: наличие UI в AC29 не доказывает доступность JSON/API вызова; остаётся NOT_VERIFIED.

## Доказательные ворота
SOURCE: PASS (релизные заметки); BUILD: NOT_VERIFIED локально; INSTALLED: NOT_VERIFIED для перечисленных функций; LIVE: NOT_VERIFIED; ACCEPTED: NOT_VERIFIED.

Следующий критерий ГОТОВО: исходный JSON-контракт каждой команды в теге, соответствующем установленной версии, плюс сопоставление с реализацией APA; никаких новых live-операций.
