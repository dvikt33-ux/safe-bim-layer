## C01 — Single-Plane Roof Deconstruct + native APA roof readback | 100/100
**BUILD-01:** крыши, AC→GH после правки в AC. **Готовое:** Graphisoft GH Live Connection AC29 Deconstruct Roof, только Single-Plane; многоплоскостная крыша исключена. **Источник/версия:** https://help.graphisoft.com/AC/29/INT/GC.pdf, AC29 guide; add-on build3000 доступен https://www.graphisoft.com/en-de/downloads/add-ons/rhino-grasshopper/ . **Лицензия:** add-on download, базовые AC/Rhino лицензии отдельно. **Контракт:** AC Single-Plane Roof→GH reference geometry/Settings; ручной Send Changes. **Риск:** Multi-Plane unsupported; не доказывает same-GUID write-back. **Задание №2:** сохранить multi-plane roof в native APA/SceneWriter; использовать независимый GetDetails/geometry readback; для single-plane составить GH reference preflight. **ГОТОВО:** таблица типа крыши и реального readback с GUID без изменений PLN. **Статус:** SOURCE, NOT_INSTALLED.

## C02 — GH hosted Door/Window + точный GDL identity | 100/100
**BUILD-01:** окна/двери на стенах с сохранением BIM типа. **Готовое:** GH Wall→Door/Window, Horizontal Distance или Door/Window Point, существующая Archicad Library Part. **Источник:** https://help.graphisoft.com/AC/29/INT/GC.pdf (AC29). **Лицензия:** штатное соединение, AC/Rhino отдельно. **Контракт:** Wall-type input обязателен; расстояние вдоль reference line либо перпендикулярная проекция точки. **Риск:** GDL library part identity не равен favoriteName, manual Wall host обязателен, часть внутренних GDL параметров недоступна без изменения кода детали. **Задание №2:** в G2 read-only сравнить host GUID, reference endpoints, insertion point, libraryPartName/GUID, width/height/sill; использовать готовые defaults/Favorites. **ГОТОВО:** доказанный native host/type/library identity, без нового writer. **Статус:** SOURCE.

## C03 — GDL library parameter access limitation | 98/100
**BUILD-01:** параметрические семейства/окна. **Готовое:** Object Settings Use existing Library Part / Select Archicad Library Part. **Источник:** https://help.graphisoft.com/AC/29/INT/GC.pdf. **Лицензия:** штатное AC29/Rhino8. **Контракт:** выбор детали и exposed Settings, не универсальное изменение GDL параметров. **Риск:** руководство требует изменения program code для доступа GH к внутренним GDL параметрам; противоречит политике «ни строчки кода». **Задание №2:** составить список только доступных без GDL правки параметров каждого семейства; остальное NOT_SUPPORTED, не обходить. **ГОТОВО:** матрица editable/readonly/unavailable для реальной AC29 библиотеки. **Статус:** SOURCE.

## Сводный выбор
Первый обязательный маршрут: Graphisoft GH-AC Live Connection для **GH-owned native элементов** плюс существующий APA SceneWriter для **APA-owned элементов**. Один element GUID/набор свойств — один writer. Speckle только кандидат независимого read/QA; Tapir GH — кандидат визуальных команд без права второго write; RhinoPlayer — потенциальный no-code runner, не доказанный автоматический sync. Автоматическая симметричная синхронизация всех трёх программ NOT_FOUND/NOT_PROVEN.
