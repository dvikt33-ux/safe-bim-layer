# APA №1 | 12Z | Семь готовых маршрутов для тройной связки

Оценки важности 0–100 экспертные, НЕ benchmark. Везде SOURCE_ONLY. Никакой установки или LIVE.

## C01 — Graphisoft Grasshopper–Archicad 29 Live Connection (100/100)
**Операция:** GH параметрическая сборка → native AC Wall/Slab/Beam/Column/и доступные Design Components; обратное чтение AC через Deconstruct. **Версия:** AC29 Live Connection build 3000, Windows, Rhino 7/8; официальный релиз 01.10.2025. **Источник:** https://www.graphisoft.com/en-de/downloads/add-ons/rhino-grasshopper/; руководство https://help.graphisoft.com/AC/29/INT/GC.pdf. **Лицензия:** дистрибутив на официальной странице; базовые Rhino/AC коммерческие права проверить отдельно. **Направления:** GH→AC native write; AC→GH reference/deconstruct; произвольный AC↔GH↔Rhino overwrite без потерь не доказан. **Установка:** отдельно санкционированная установка нужного Windows build, открыть AC/Rhino/GH, выбрать порт и GH документ, старт связи. **Риск:** GH authoritative geometry, GH update может перезаписать AC edits. **Критерий:** native GUID/тип/материал/story после Save/Open. **№2:** построить матрицу native Design/Deconstruct компонентов.

## C02 — Deconstruct + Extract Settings + Input (97/100)
**Операция:** использовать существующие AC Walls/Beams/Stories/Composite/Materials/Favorites как вход алгоритма GH. **Источник:** https://help.graphisoft.com/AC/29/INT/GC.pdf; https://community.graphisoft.com/t5/Modeling/Grasshopper-Archicad-Live-Connection/ta-p/304037. **Версия:** руководство AC29. **Лицензия:** в составе Live Connection; отдельно права AC/Rhino. **Направление:** AC→GH данные; результат может быть новым AC элементом. **Ограничение:** не гарантирует сохранение GUID исходного элемента и не является обратной записью AC→GH→AC в тот же элемент. **Критерий:** прочитаны свойства, геометрия и различие исходного/нового GUID. **№2:** составить два read-only сценария AC→GH (Wall, Beam) и ownership.

## C03 — Synchronize Boolean Toggle (99/100)
**Операция:** управляемая публикация целых групп GH Design Components в AC только после готовности параметров. **Источник:** https://help.graphisoft.com/AC/29/INT/GC.pdf; https://community.graphisoft.com/t5/Modeling/Grasshopper-ARCHICAD-Live-connection/ta-p/303564. **Версия:** AC29 guide + рекомендации Graphisoft. **Лицензия:** штатные компоненты GH. **Направление:** GH→AC. **Ограничение:** FALSE останавливает связь, не гарантирует удаления/отката; mass update может зависнуть. **Критерий:** при FALSE AC inventory не меняется; при TRUE на санкционированном scratch меняется только разрешённая группа. **№2:** ручные gates по группам и preflight unit/story/host.

## C04 — Story Plane + Composite/Material/Favorite Inputs (98/100)
**Операция:** создавать стены/перекрытия на реальных этажных плоскостях, выбирать AC attributes из текущего PLN. **Источник:** https://help.graphisoft.com/AC/29/INT/GC.pdf; https://community.graphisoft.com/t5/Modeling/Grasshopper-ARCHICAD-Live-connection/ta-p/303564. **Версия:** AC29 guide, исторические tips. **Лицензия:** штатная Live Connection. **Направление:** AC→GH параметры, GH→AC native элементы. **Ограничение:** Home Story зависит от геометрии, не только от имени; literal GUID из старого PLN непереносимы. **Критерий:** two-story model, GetStories и независимый readback материалов/этажей. **№2:** сравнить с PR74 storyBindings/material IDs.

## C05 — Rhino 3DM Hotlink в AC29 (65/100)
**Операция:** повторно используемый Rhino-контекст/свободная геометрия без копирования вручную. **Источник:** https://help.graphisoft.com/AC/29/INT/_AC29_Help/120_Interoperability/120_Interoperability-43.htm; https://help.graphisoft.com/AC/29/INT/_AC29_Help/120_Interoperability/120_Interoperability-41.htm. **Версия:** AC29. **Лицензия:** встроенная функция Archicad, права AC/Rhino отдельно. **Направление:** Rhino .3dm→AC Hotlink, обновление через управление Hotlink; не real-time GH write. **Ограничение:** imported objects/GDL, не native Wall/Roof, неизменяемые settings, зависимость от путей и обновления. **Критерий:** source revision, Update, повторный readback количества и слоя. **№2:** использовать как reference-only fallback, не как BUILD-01 native route.

## C06 — Morph Solid + Mesh-Brep conversion (78/100)
**Операция:** свободная форма Rhino/GH→AC Morph с Building Material/Layer/ID/Properties. **Источник:** https://help.graphisoft.com/AC/29/INT/GC.pdf. **Версия:** AC29. **Лицензия:** Live Connection + Rhino. **Направление:** GH→AC native Morph, не native Slab/Wall/Roof. **Ограничение:** mesh tessellation, возможное изменение топологии и объёма. **Критерий:** закрытый solid, bbox/volume/triangles, материал, Save/Open. **№2:** применять для уникальных деталей/контекста, не заменять стены/крыши.

## C07 — Rhino 8 Blocks / Linked Blocks (54/100)
**Операция:** параметрические повторяемые элементы Rhino, обновление всех экземпляров через замену определения. **Источник:** https://docs.mcneel.com/rhino/8/help/en-us/seealso/sak_blocksgroups.htm. **Версия:** Rhino 8 Windows. **Лицензия:** встроенный инструмент коммерческого Rhino. **Направление:** внутри Rhino; не автоматическая синхронизация AC. **Ограничение:** Rhino Block ID/Instance не AC GUID; требуется отдельный GH native element route. **Критерий:** один edit block→обновлены N Rhino instances; при AC sync readback N native elements. **№2:** ограничить применимость повторяемыми декоративными/сложными объектами, не обещать BIM-семантику.
