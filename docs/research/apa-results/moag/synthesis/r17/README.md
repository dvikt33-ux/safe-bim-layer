# МОАГ R17 — доказательный секторальный контур Нижнего блока и контроль идентичности лестниц

**Состояние:** `QUALITATIVE_SOURCE_SECTOR_AND_PORTAL_CONSTRAINTS`. Это не точная 3D-реконструкция и не готовая геометрия оболочки станции.

База: R16, [draft PR #202](https://github.com/dvikt33-ux/safe-bim-layer/pull/202), коммит `31fb9e2829ccffd998d4f06a892921366c8a29a3`. Реальные исходные R09–R16, авторские изображения, `main` и Archicad сохраняются. Подключены исходные R15 12 условных объёмов, 197 индексов, 52 маршрута, 378 этапов (25 привязанных к объёмам, 353 с незакрытыми привязками), R16 качественная развилка B1-065.

## 1. Постраничная проверка и новые факты

Книга II, <https://loveread.ec/read_book.php?id=53370&p=14> (B2-014), содержит **прямое** сопоставление:

- Жилые базы расположены **в другой части Нижнего** по отношению к ангарному отсеку. Участки функционально различимы. Это не конкретная дистанция, не стороны света, не прямоугольные зоны и не требование, чтобы *вся* часть с базами имела одинаковый физический пол.
- В ангарном секторе после развилки **короткий боковой проход приводит в широкую ангарную магистраль**, возле которой двери ангаров; в первом осматриваемом ангаре операторские подняты почти к потолку.
- Нельзя отсюда выводить, что каждый коридор Нижнего относится только к одной из двух категорий, или что их габариты известны.

Книга I, <https://loveread.ec/read_book.php?id=48197&p=76> (B1-076), подтверждает для конкретного **высокого круглого зала**: повреждённый лестничный подъём к полукруглому верхнему мостику, **дверь с мостика в пультовую** и **следующую дверь в жилую комнату**. Мостик проходит только примерно по половине зала, не является цельным дополнительным полом. Зал с тележками не следует отождествлять со всеми ангарами.

Оба первоисточника сверены непосредственно по доступным страницам, кроме уже существующих реестров.

## 2. Что компилируется в реальный общий CP-SAT

Добавлен **один новый источниковый тип ограничения**: `BASE-SECTOR != HANGAR-SECTOR` — два условных категориальных значения в [0..2], без физического XYZ, метрики и оценки количества всех секторов на станции. Это не координатная задача; правило лишь запрещает гипотезу о полном отождествлении двух функциональных частей Нижнего.

В общей модели R15+R16 уже зарегистрированы как исходные точные R09 связи:

| Исходное ребро | Содержимое | Статус в R17 |
|---|---|---|
| `MOAG-RG-E69` | Верхний мостик → пультовая, дверь | Прямое доказательное дверное отношение B1-076 |
| `MOAG-RG-E70` | Пультовая → жилая комната, следующая дверь | Прямое доказательное дверное отношение B1-076 |
| `MOAG-RG-E20` | Магистраль ангаров → первый ангар | `access_to` с дверным описанием B2-014; *не менять тип R09 на `door_to`* |

R17 компилирует их как три **символических флага наличия источникового перехода**. Не создаются: новый физический портал, габарит двери, трасса XY, переходный коридор или квадратный бетонный объём. Порядок посещения в R14 по-прежнему не означает автоматический прямой проход.

## 3. Пять объектов для последующего размещения

Существующие индексные записи и количество **не привязанных к сценарным боксам посещений** (не количество комнат):

| Индекс | Содержание | Количество | Риск поспешного размещения |
|---|---|---:|---|
| `MOAG-G-0021` | Запечатанная/неисследованная зона | 11 | Граница зоны меняется по сюжету, не одно помещение |
| `MOAG-G-0053` | Старый закрытый грузовой ангар/сектор | 8 | Не доказано тождество с другими ангарными боксами |
| `MOAG-G-0014` | Цех переработки | **6** | Есть функциональный объект, но ещё нет подтверждённого объёмного контура |
| `MOAG-G-0017` | Магистраль ангаров | 4 | Протяжённый переход, не компактный зал |
| `MOAG-G-0059` | Повреждённая лестница к мостику | 4 | Индекс встречается в нескольких сценах, общая лестница всех операторских не доказана |

**Поправка к предыдущему сообщению:** у цеха переработки 6, а не 5 непривязанных посещений. Всего по пяти индексам — **33** этапа.

### Независимая проверка потенциального смешения лестниц

`RT015-J` — подъём по остатку лестницы в конкретном круглом зале, B1-076. `RT023-A` — спуск из старой пультовой к ангару, B1-104. `RT024-G` и `RT024-J` — путь по лестнице к/из диспетчерской, B1-110/113.

У всех четырёх посещений один исходный индекс `MOAG-G-0059`. **Это ещё не доказательство их геометрического тождества.** R17 сохраняет отдельные координаты/домены и открытый вопрос соответствия. Две крайности одинаково запрещены: механически слить все лестницы или без доказательств создать четыре разных.

### Другие ограничения источников

`MOAG-RG-E144` (запечатанная область → ангарные подходы) — **маршрут через просторный коридор**, НЕ прямая дверь.
`MOAG-RG-E99` (кандидат тождества двух ангарных коридоров) остаётся в карантине.
`MOAG-RG-E61` (старый грузовой ангар заменён новыми на Третьем) — историческая преемственность, НЕ пространственная смежность.
`MOAG-RG-E80` (слух/запах цеха переработки при движении) — относительная доступность по маршруту, НЕ прямой проём.

Эти связи перечислены как доказательственный контроль, а не насильно превращены в координаты.

## 4. Вычислительные испытания

```powershell
python -m pip install -r tools/moag_topology/requirements-r11.txt
python tools/moag_topology/bootstrap_r11.py
python tools/moag_topology/lower_evidence_r17.py --out moag-r17-run
python -m unittest discover -s tests -p test_moag_lower_r17.py -v
```

Реальные Python OR-Tools CP-SAT и MiniZinc→CP-SAT получают **SAT** полной модели R16+R17. Python-свидетель воспроизводится MiniZinc.

Отрицательные контрпримеры (намеренные, НЕ противоречия книги):

1. `BASE-SECTOR == HANGAR-SECTOR` допустимо **без** нового источникового ограничения, но **UNSAT** с B2-014. Конфликтное ядро содержит B2-014 и синтетическое требование; воспроизвести ядро обоими решателями.
2. Принудительно объявить дверь E69 отсутствующей — SAT без источникового флага, UNSAT при включённом B1-076.

Ограничение действительно уменьшает **только категориальную** область решений. **Границы физических координат X/Y/Z не сокращаются** — так и записывать. Техническая целостность проверяется отдельными тестами и полным CI R11–R17 на Windows/Linux.

## 5. Границы готовности

- Нет подтверждённого полного внешнего контура, ширин ангарных проходов, габаритов баз и точной формы обоих колец.
- Нельзя выдать физическую посадку пяти приоритетных объектов в численную сетку R13 за доказанный прогресс: R17 сохраняет 25 привязанных и 353 непривязанных посещения.
- Нельзя приравнивать *доступ к сектору* к двери конкретного помещения.
- R09 593/845, R05 профили, R11–R16, иллюстрации, `main` и Archicad **не изменять**.

**Следующая серьёзная задача:** поэпизодно подтвердить или опровергнуть отождествление старых ангаров и лестниц, привязать подтверждённые помещения к разрезам через реальные источниковые домены и восстановить обоснованные, а не декоративные маршруты.
