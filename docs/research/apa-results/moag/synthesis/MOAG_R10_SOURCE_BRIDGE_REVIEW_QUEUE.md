# МОАГ — R10 | Очередь доказательных соединений из единого графа R09

**Состояние:** `SOURCE_PAGE_TRIAGE_ONLY / REVIEW_REQUIRED / GEOMETRY_NOT_APPROVED`.

## Назначение

R09 остаётся **единственной канонической предметной моделью**; R10 не делает третью версию станции. Вместо этого формируется **проверяемая очередь постраничного чтения и адресной проверки кандидатов-связок** из файла `moag-r10-review-frontiers.json`.

R10 объединяет четыре типа нерешённых вопросов:

1. **12 известных стационарных объектов**, ещё не имеющих доказанной привязки. Для каждого — две альтернативы соседства и безусловное «местоположение неизвестно». Отображается идентификатор доказательного компонента каждого предлагаемого якоря; разные компоненты означают *только потенциальную* пользу от будущего доказательства.
2. **18 разрывов повествовательных маршрутов** с двумя известными границами. Геометрия, число промежуточных помещений и возможный обход через другие глобальные уровни не фиксируются.
3. **306 наблюдаемых последовательных переходов**, для которых не доказаны непосредственная дверь и промежуточная планиметрия. Эти переходы уже существуют внутри качественного доказательного графа R07; **они не считаются 306 новыми соединениями компонентов**.
4. **5 спорных соответствий старых концептуальных и уточнённых индексов**. Глобальное тождество, совпадение геометрического объёма и повторное начисление площади запрещены без адресного подтверждения.

## Что вычисляется

Программа разрешает ссылки `P-...`, `LR-Bn-nnn` и `Bn-nnn` на конкретные страницы реестров четырёх книг. На одной странице может встречаться несколько исследовательских сигналов. Их совместное присутствие — основание **перепроверить текст**, но не доказательство непосредственного прохода между объектами.

Приоритет страницы определяется детерминированной **эвристикой очереди**:

`8 × количество изолированных объектов + 5 × разрывы маршрутов + 4 × вопросы тождества + min(6, количество последовательных перемещений)`.

Это **не вероятность, не коэффициент достоверности и не архитектурный факт**. При равенстве приоритета впереди стоят страницы, ещё не помеченные в реестре как прочитанные целиком. Отметка о чтении не заменяет независимую повторную проверку. Неразрешённые ссылки на источники не выкидываются: экспортируются отдельно.

## Что не допускается

- По соседству текстовых упоминаний создавать дверь, коридор либо метрические координаты.
- Объявлять гипотезу симметрии обязательной или применять её к масштабу и геометрии станции.
- Из-за уже существующей последовательности маршрута считать два конца непосредственно соседними.
- Смешивать временное эксплуатационное состояние ворот с существованием проёма.
- Объединять глобальные этажи по локальной лестнице или верхней галерее.
- Складывать площади концептуального индекса и его уточнения без доказательства непересечения.

**Инварианты:** 575 доказательных узлов, 761 доказательная связь, 39 качественных пространственных компонентов, 25 прямых связей доступа; итоговый R09 — 593 узла и 845 отношений. R10 **не добавляет ни узла, ни ребра** в исходный граф.

## Выпуск воспроизводимой очереди

```bash
python tools/moag_topology/review_frontiers_r10.py --out moag-r10-review-frontiers.json
python -m unittest discover -s tests -p 'test_moag_*.py' -v
```

**Правило следующей доказательной итерации:** открыть первоисточник, зафиксировать конкретные два именованных объекта, тип отношения (прямой доступ / маршрут через неизвестное / функциональная связь / тождество), контекст уровня и состояние, проверить отрицательные тождества и только затем предлагать новую доказательную связь отдельной ревизией. Если источник не даёт однозначного результата, сохранение неизвестного **является правильным итогом**, а не ошибкой.

**До независимой проверки:** `geometry_approved=false`, `archicad_write=false`; `main` и Archicad не изменяются.
