# МОАГ — R07 | Единый доказательный многослойный граф

**Статус:** `SCHEMA_UNIFIED / TOPOLOGY_PARTIAL / NOT_GEOMETRY / REVIEW_REQUIRED`

## Достигнуто

В одном сериализованном проверяемом графе R07 содержатся **575 узлов**:
**197** индексов физических объектов, систем и концептов станционной структуры;
**378** наблюдений шагов 52 маршрутов. Зафиксированы **761 типизированная
связь**. Подтверждённый качественный граф на данный момент разбит на **39
компонентов с индексами**, включая **25 изолированных**; граф прямых доступов
содержит **25** явно подтверждённых связей и **173** компонента. Графовые
узлы и компоненты не равны физическим помещениям один к одному.

Единство графа означает **один словарь индексов и один формат
доказательств**, а НЕ доказанную геометрическую связанность, площадь,
высоту или доступность всей станции. Строительная модель остаётся
неподтверждённой.

## Отношения нельзя подменять друг другом

1. `EXPLICIT_ACCESS` — источник утверждает конкретный непосредственный
   дверной/лестничный/шлюзовой проход. Его эксплуатационное состояние и
   метрическая геометрия пока неизвестны.
2. `OBSERVED_TRAJECTORY` — посещение индексированного места или порядок
   перемещения персонажей. Маршрут может содержать неизвестные коридоры,
   а повторы наблюдений не становятся дополнительными комнатами.
3. `SOURCE_QUALITATIVE_ASSOCIATION` — подтверждённое соседство в смысле
   функциональной зоны, объёмная вложенность, действовавшая связь через
   промежуточный путь, но **не обязательно прямой проход**.
4. `NONCONNECTING_CONTEXT` — косвенная информация, обзор, близость,
   неподтверждённая пространственная гипотеза.
5. `REFERENT_CROSSWALK_NOT_PHYSICAL_IDENTITY` — 22 соответствия раннего
   концепта и уточнённого индекса. Это не независимые площади и не доказанная
   идентичность границ.
6. `PROHIBITED_IDENTITY_MERGE` и `PROHIBITED_IDENTITY_OR_INFERENCE` —
   запреты на ложную идентификацию объектов или вывод из отсутствующего
   доказательства. Отдельно отмечаются спорные по станции люки.
7. `UNVERIFIED_CANDIDATE_NOT_A_CONNECTION` — гипотеза в очереди новой
   проверки. Присутствие такого ребра **не** склеивает компоненты.
8. `DOCUMENTED_GAP_NO_ROUTE_LINK` — 18 границ необъяснённых участков
   маршрутов: нигде не заменяются придуманными прямыми проёмами.

Программа `tools/moag_topology/unified_evidence_graph_r07.py` переносит
разрешённую топологию R06, типизированный граф прямых доступов R06,
исключения идентичности R04/R05, кросс-индексы, нерешённые кандидаты и
отсутствующие переходы в единый источник для будущих графических и BIM
потребителей. Новый код **не** переписывает R04/R05/v2, а создаёт проекцию.

## Устранение противоречий в старых гипотезах

- `H06-001` **РАЗРЕШЕНА** ссылкой на уже существующее `S06-008`. В
  [книге II, стр. 15](https://loveread.ec/read_book.php?id=53370&p=15)
  участники сообщают, что катера, найденные в соседних ангарах, придётся
  запускать через действующий шлюз рабочего ангара. Указание на
  «здешний шлюз» уточняет референт. Запись старого сомнения сохраняется
  для аудита, но не считается открытой и не дублирует реальное ребро.
  Не следует считать тот же шлюз отдельным физическим проёмом каждого
  соседнего ангара.
- `H06-003` **ОТКЛОНЕНА**: старый изолятор на **Третьем** нельзя
  отождествлять с `MOAG-G-0030`, школой/экзаменационным блоком **Второго**.
  Это одновременно неподтверждённая идентичность и несовместимость
  глобальных уровней. Отказ сохранён как отдельное отрицательное
  свидетельство, но физические компоненты не соединяются.
- `H06-002` **ОТКРЫТА**: полукруглый ряд кладовых и коридор для погрузчиков
  находятся на Третьем, однако текст P-570 не доказывает тождество
  описанного прохода именно грузовой магистрали `M-L3-LOG-001`.
  Связь видна в мастере как вопрос, не как готовый маршрут.

## Необходимые подтверждения

На момент R07 требуются новая первичная проверка для **12** остающихся
изолированных стационарных индексов, **18** разрывов маршрутов,
**5** глобальных соотношений ранних/уточнённых идентификаторов, а также
перепроверка **3** объектов, которые могли быть ошибочно перенесены со
второй станции. В системном реестре первого полного чтения 260/412
страниц; 152 страницы остаются за границей зарегистрированного
полного прохода. Отсутствуют метрические XY и окончательная увязка Z,
пятен помещений, лестниц и высоких сквозных объёмов.

## Команда и критерии приёмки

```bash
python tools/moag_topology/unified_evidence_graph_r07.py \
  --out moag-r07-unified-evidence.json
python -m unittest discover -s tests -p 'test_moag_*.py' -v
```

Отдельные проверки принуждают (а) сохранить 575 узлов, (б) не сделать
ни одного перехода из отрицательных и проверочных рёбер, (в) отклонить
воскрешённую H06-003, (г) проверить, что разрешённая H06-001 совпадает
с принятой S06-008, (д) сохранить карантин чужой станции и
(е) не превращать 18 неизвестных маршрутов в прямые соединения.

**Запрет:** запись в Archicad, слияние `main`, создание сплошных
палуб из частичных галерей и утверждение геометрии не выполняются.
Промежуточные файлы публикации проверяются в GitHub Actions отдельно
для Python 3.11 и 3.12.
