# R23 — последовательная реконструкция после R22

База следующей работы — принятый результат R22 и точный коммит его PR, а не автоматически актуальная main. Не выполнять эти этапы в рамках R22 и не переносить их в Archicad без отдельного задания.

1. **Одна область: уровень восстановленного прохода B1-105.** Прочитать непрерывную сцену B1-100–108, проверить формулировку названия уровня по доступному независимому изданию. Сохранить источник и разрешить либо явно оставить неоднозначность. Готово: регрессионная проверка не допускает неподтверждённой смены глобального уровня.
2. **Одна область: ворота запертого сектора.** Построить событийную цепь только для 11 употреблений SEALED и необходимых соседей: подход, ремонт, открытие, пересечение, закрытие, ключ. Принимать тождество конкретного портала по непрерывности сцены или уникальному ориентиру. Готово: рабочий граф одной доказанной цепи с сохранёнными неизвестными ответвлениями; число физических дверей не выводится из числа событий.
3. **Одна область: эквивалентный зал CH/AH-OLD.** Сопоставить существующие профили площадей, объёмов, R12-ярусы и R13 сценарные представления. Не складывать две модели одного зала и не приравнивать их XYZ без геометрического обоснования. Готово: единый учёт одного объёма или явно взаимоисключающие сценарии, реальные SAT/UNSAT и сохранение источников.
4. **Одна область: лестницы и рубки этого зала.** Сначала конкретная лестница, затем конкретные помещения. Тождество зала — контекст, не доказательство тождества каждого внутреннего элемента. Готово: уменьшение неопределённости с новым источником либо честное сохранение SAME/DIFFERENT как двух SAT-вариантов.
5. **Одна область: грузовая сеть и действующий ангар.** Разделить грузовой сектор, коридор, тёмный ангар и высокий старый зал. Проверить связь действующего ангара с лодочными ангарами. Готово: воспроизводимый путь с промежуточными этапами; новых непосредственных проходов без текста нет.

После каждого этапа: рабочая минимальная модель → реальные решатели → сценарий с отрицательным контролем → фиксация результата → следующий этап. Параллельное разворачивание всех областей не требуется. Полная регрессия и неизменность книжных материалов сохраняются; параметры симметрии и численные размеры имеют статус гипотез.
