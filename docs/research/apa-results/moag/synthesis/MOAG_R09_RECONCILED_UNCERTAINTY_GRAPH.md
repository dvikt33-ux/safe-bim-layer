# МОАГ — R09. Один граф доказательств и гипотез без потери неизвестных проходов

**Статус:** `ONE_MASTER_GRAPH / HYPOTHESES_NONBINDING / GEOMETRY_REVIEW_REQUIRED`.

## Зачем понадобился R09

В R08 существовали **две независимые проекции** одного доказательного графа:

- `hypothesis_overlay_r08.py`: 593 узла, 825 связей; для 18 пробелов маршрутов — 18 условных нефизических заполнителей и 36 мягких рёбер; 12 слабых привязок к возможным глобальным уровням и 16 сценариев компоновки в 8 парах.
- `hypothetical_structure_r08.py`: 593 узла, 821 связь; те же 18 пропусков маршрутов, но с иными техническими идентификаторами, 24 альтернативы для 12 известных изолированных стационарных объектов, 306 наблюдавшихся переходов с недоказанной геометрией, три общие композиционные гипотезы.

Обе проекции нужны и обе остаются доступными как исходные реестры, однако для **единой реконструкции станции** формируется **один согласованный результирующий граф** `moag-r09-reconciled-uncertainty.json`.

| Отдельные нефизические заполнители неизвестных частей маршрутов | 18 |
| **Узлы единого графа R09** | **593** |
| Неизменяемые отношения R07 | 761 |
| Условные концы 18 неописанных интервалов | 36 |
| Слабые области поиска для стационарных объектов | 12 |
| Варианты структурных и функциональных схем из первого R08 | 16 |
| Дополнительные **различные** привязки объектов из второго R08 | 20 |
| **Рёбра единого графа R09** | **845** |
| Повторные варианты второго R08, сохранённые как перекрёстные ссылки | 4 |
| Наблюдавшиеся переходы без доказанной геометрии промежуточного пути | 306 |
| Компоненты качественной доказательной топологии | 39 |
| Подтверждённые отношения прямого доступа | 25 |

**Почему 845, а не 821 + 825:** обе версии R08 содержат одни и те же **761** доказательных отношений R07 и **18** неизвестных отрезков. Их нельзя удваивать. Среди 24 дополнительных вариантов по конкретным объектам **четыре совпадают по парам концов** с первыми 16. Эти четыре оставлены как самостоятельные *обоснования*, но не как новые дублированные рёбра:

- библиотека с овальным окном ↔ жилое кольцо;
- та же библиотека ↔ Главная площадь;
- оружейная ↔ грузовой коридор;
- полукруглый ряд маленьких кладовок ↔ грузовой коридор.

Совпадение концов **не доказывает тождество объяснений**: кольцевое расположение и функциональная привязка могут предполагать разные геометрические варианты. Поэтому файл хранит исходные идентификаторы и ссылки в `overlapping_proposals_kept_as_cross_references` с пометкой `same_pair_only_not_equivalent_spatial_hypothesis`.

## Три уровня неопределённости маршрутов

1. **Непосредственный проход** — только при отдельном доказательстве двери/лестницы/шлюза, не при любой последовательности посещений.
2. **306 описанных последовательных перемещений** — факт смены наблюдаемого места; неизвестно, какие промежуточные повороты, двери или проходы были на траектории.
3. **18 повествовательных пропусков** — факт отсутствия сведений о промежуточном передвижении; ни число помещений, ни существование *нового* коридора из этого не выводится.

Оба варианта R08 представляют эти 18 пропусков разными идентификаторами. R09 связывает их в `gap_placeholders` **один к одному**, а не конструирует 36 разных коридоров.

### Правило вертикальных обходов

Для каждого пропуска раздельно фиксируются **возможный общий уровень концов** и **объединение их уровневых областей**, поскольку это *разные математические множества*. Ни одно не является жёсткой областью высот промежуточного пути.

Если обе описанные точки находятся на Втором, путь всё равно мог проходить через Нижний либо Верхний и вернуться. Пока источник не исключает такого обхода, R09 оставляет `global_deck_domain_of_actual_intermediate_path = [1,2,3]` и не выдумывает лестницу или новую палубу.

## Симметрия — тестируемая гипотеза, а не геометрия

Восемь пар альтернатив R08 проверяют кольцевую/радиальную организацию, модули ангаров, расположение лифтов, библиотек, оружейной, изолятора и кладовых. Три общих композиционных образца (потенциально радиальные коридоры Верхнего, повторяемые ангарные ячейки Нижнего, возможная общая ось глобальных блоков) хранятся **как метаданные**. Они не превращаются в дверные рёбра и не требуют симметричного корпуса.

Для 12 неподключённых стационарных индексов остаются **по два возможных сценария размещения** плюс принципиально допустимый вариант **«ничего не привязывать до новых доказательств»**. Никакая гипотеза не сужает утверждённый глобальный уровень объекта и не даёт численных XY/Z или размеров.

## Доказательная неприкосновенность

Объединённая модель R09 не изменяет исходные 575 узлов, 761 связь, 39 качественных компонентов, 25 прямых связей, 197 пространственно-концептуальных индексов и 157 расчётных профилей площадей. Прямое перемещение из условного ребра в доказательный граф запрещено. Для каждого варианта сохраняются исходные идентификаторы, доказательство существования элемента, отличие от доказательства расположения и возможность опровержения.

Код [`reconcile_uncertainty_r09.py`](../../../../../tools/moag_topology/reconcile_uncertainty_r09.py) сверяет две базы R08, не позволяет потерять неизвестный переход, отвергает несовпадение исходного R07 и запрещает использование предположения как прямого прохода. Основной машиночитаемый выход `moag-r09-reconciled-uncertainty.json` экспортируется GitHub Actions.

```bash
python tools/moag_topology/reconcile_uncertainty_r09.py \
  --out moag-r09-reconciled-uncertainty.json
python -m unittest discover -s tests -p 'test_moag_*.py' -v
```

**Следующие доказательные действия:** проверять недостающие 152 страницы основного полного постраничного реестра; обнаруживать реальные связующие узлы между 39 компонентами; проверять пять спорных глобальных отождествлений; уточнять 12 отдельных стационарных объектов и реальный тип промежуточного движения в 18 разрывах. Только исходные наблюдения могут повышать гипотезу до прямой или качественной связи.

**Статус по выпуску:** `REVIEW_REQUIRED`. Исходные книги и графы R04–R08 не редактируются этим сборщиком, запись в Archicad и объединение в `main` не выполняются.
