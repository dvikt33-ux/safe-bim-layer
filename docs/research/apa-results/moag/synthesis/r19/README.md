# МОАГ R19 — история нижних грузовых ангаров без ложного пространственного слияния

**Статус:** `HISTORICAL_FUNCTION_AND_NONMETRIC_IDENTITY`. База: [R18 draft PR #204](https://github.com/dvikt33-ux/safe-bim-layer/pull/204), коммит `9d8802de8a27da01746c5eee3213b285ff657f0e`.

## Источниковый результат

**Важно:** R19 не заявляет повторного прямого чтения опубликованных веб-страниц. Во время R19 сайт книжного первоисточника был недоступен веб-инструменту. Для решения использованы ранее зарегистрированные **постраничные наблюдения** B1 и прямые URL из `v2/page_observations.json`, уже проверенные в предшествующих версиях. До геометрического утверждения источники требуется перечитать непосредственно.

| Проверенный в реестре текст | Источник | Правило |
|---|---|---|
| Нижние помещения исторически служили центром управления грузовыми ангарами, которые принимали крейсеры | [B1-082, P-240](https://loveread.ec/read_book.php?id=48197&p=82) | `M-L1-CG-001` — существующий исторический нижний комплекс, не автоматически один ангар |
| Основные грузовые операции в Нижнем прекратились после открытия новых грузовых ангаров Третьего | [B1-083, P-243](https://loveread.ec/read_book.php?id=48197&p=83) | **Два разных глобальных комплекса**; `NEW_UPPER_COMMISSIONED < OLD_LOWER_PRIMARY_HALTED` |
| Старый нижний ангарный комплекс позднее принимал пищу и лекарства малыми челноками-автопилотами | [B1-091, P-265](https://loveread.ec/read_book.php?id=48197&p=91) | `OLD_LOWER_PRIMARY_HALTED < LATER_SMALL_SHUTTLE_SUPPLIES` |

Знаки `<` здесь означают только порядок в историческом времени. Переменные решателя — целочисленные **порядковые ранги**, **не календарные годы**, не метры и не этажи.

Нижний `M-L1-CG-001` и новый верхний `M-L3-CG-001` — не один физический грузовой комплекс. Существующее отношение R03 `MOAG-R3-RC-008 PREDECESSOR_CARGO_FUNCTION_OF` и источник P-243 сохранены; **историческое функциональное преемство не является физической смежностью или дверью**.

### Что прямо НЕ установлено

- `MOAG-G-0053` (концептуальная метка исторического грузового анклава) и `M-L1-CG-001` (R03 комплекс) могут представлять один объект или разные детализации: пока не сливать.
- Комплекс `M-L1-CG-001` может включать высокий старый ангар эпизода B1-110 либо относиться к иному сектору. Из P-240 + P-313 это однозначно не следует.
- Ангар со спящими взрослыми `MOAG-G-0057` не приравнивается без доказательства к высокому ангару `M-L1-AH-OLD-001`.
- Исторический контрольный центр `M-L1-CG-CTRL-001` **не** становится автоматически той же поднятой диспетчерской, что `M-L1-AH-OLD-CTRL-001`, только потому что оба связаны со старой грузовой историей.

Оставлены все шесть неразрешённых пар R18. Адресно перепроверены по обоим вариантам («одно»/«разные») три грузовых/староангарных пары из них.

## Вычислительный эксперимент

R19 использует тот же комплексный адаптер `integrated_spatial_r15.py` и реальный MiniZinc CP-SAT + Python OR-Tools; не вводит собственную процедуру поиска решений.

```powershell
python tools/moag_topology/bootstrap_r11.py
python tools/moag_topology/cargo_history_r19.py --out moag-r19-run
python -m unittest discover -s tests -p test_moag_cargo_r19.py -v
```

Обязательные проверки:

1. Общий SAT с источниковым неравенством нижнего/верхнего грузовых комплексов и двумя хронологическими отношениями, повторная проверка фиксированного Python-свидетеля в MiniZinc.
2. Искусственное `LOWER_COMPLEX == THIRD_COMPLEX` — UNSAT только при включённом источниковом различии B1-083.
3. Искусственное открытие Третьего **не раньше** прекращения главной грузовой работы Нижнего — UNSAT при B1-083.
4. Искусственные поздние поставки **не позже** прекращения основной грузовой работы Нижнего — UNSAT при B1-091.
5. Конфликтные ядра должны включать тестовое и источниковое ограничения, воспроизводиться обоими backend; при отключении соответствующей семьи источник-специфических ограничений противоречие должно исчезать.
6. Для трёх нерешённых староангарных пар доказать SAT **обоих** вариантов, без принуждения к одной геометрии. Сохранить полную цепочку тестов R11–R19 на Windows и Linux.

Файлы результатов: `historical-source-contract.json`, `results.json`, MiniZinc входные файлы и stdout/stderr, ядра искусственных конфликтов. Точная дата запуска, длительности и факт работы системы станцией в заданном году **не выводятся**.

## Границы готовности

- Не создана новая комната, не изменены граф R09 (593 узла / 845 связей), книги, авторские иллюстрации, исходные R11–R18 и Archicad.
- Сохраняются 52 маршрута, 378 стадий, 25 привязанных и 353 пока непривязанных посещения.
- Ни новая геометрия XYZ, ни физические двери между грузовыми комплексами, ни внутренние размеры ангаров не определены. История функционирования **не доказывает планировку**.
- R19 не является окончательной пространственной реконструкцией. Следующий этап должен перейти к адресной постраничной проверке мест старых грузовых проходов и к установлению неравнозначности/возможной вложенности **комплекс ↔ отдельный ангар** с участием источников, а не из произвольного сценарного бокса.
