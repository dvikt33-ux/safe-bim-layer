# МОАГ / R04 — параметрические геометрические ограничения

**Параметры редактируемы; ни один численный габарит сценария не является книжным фактом.**
Исходная версия: [полный граф](../../docs/research/apa-results/moag/synthesis/full_indexed_parametric_graph_r04.json). Основные значения в нём `null`, поскольку точные метры неизвестны. Человеческий модуль 1,60 м принят по поручению пользователя; глубина обзора энергоядра ≈15 м — приблизительное наблюдение с галереи, но **не высота всей станции**.

## Запуск без Archicad

```bash
python tools/moag_topology/parametric_evaluator_r04.py \
  --overrides docs/research/apa-results/moag/synthesis/demo_override_r04_NONCANON.json \
  --out ./moag_constraint_check.json
```

Сохранённый [демо-сценарий](../../docs/research/apa-results/moag/synthesis/demo_override_r04_NONCANON.json) специально создан для проверки зависимости размеров: диаметры 1200/780/530 м, условный грузовой крейсер 260×110×75 м, два корабля в нижнем ангарах 620×290×120 м. Эти значения **не из книги и не утверждены**. Замена любого значения в JSON заново пересчитает сравнения, требования по площади стоянки, высотным зазорам и местам операторских. Проверка площади — **не доказательство, что манёвр разворота возможен**, полноценная кинематика требует траектории движения.

### Отрицательный тест
Для демонстрации отказа уменьшить `lower_old_cargo_hangar_clear_width_m` с 290 до 30. Правило `R011` должно выдать FAIL.

## Связь с настоящим APA
`--apa-rectangles` принимает список `[{"id":"x","rectangle":{"xMin":0,"xMax":30,"yMin":0,"yMax":20}}]` и импортирует реальные `contains / overlap_area / rectangle` из `scripts/archicad_semantic_spatial.py` только для анализа явно заданных прямоугольников, без создания стен или операций SceneWriter. Исходные помещения МОАГа не прямоугольные; эта проверка — дополнительный инструмент для авторских локальных габаритных оболочек, а не точная геометрия кольцевой станции. `archicad_bim_graph` применяется на более поздней стадии, когда есть квалифицированные авторские геометрические операции.
