# МОАГ R18 — доказательные тождества лестниц и старых ангаров

**Статус:** `QUALITATIVE_IDENTITY_WITH_CERTIFIED_COUNTERMODELS / NONMETRIC`. Основа — R17, черновой PR #203 (коммит `e565faa8669848e299568e1a75f68853ee445ffb`).

## 1. Объектный индекс ≠ физическая идентичность

В R14 несколько маршрутных стадий получили одну старую метку `MOAG-G-0059` / `L1-CIRCULAR-STAIRS`. Но в книге встречаются лестницы с разных сцен: остатки сломанной лестницы круглого зала, лестница из старой пультовой к ангару, подвесная лестница в поднятую диспетчерскую старого ангара. **Нельзя механически сделать одно физическое тело из одинаковой метки.**

R18 добавляет **абстрактные токены идентичности** к имеющейся единой CP-SAT модели R15+R16+R17. Их равенство означает «это точно одно физическое устройство/помещение», не равенство XYZ, не контур, не общее перекрытие.

### Прямое подтверждение тождества

| Упоминание | Тождественный физический референт | Источник |
|---|---|---|
| RT015-J, подъём по повреждённой лестнице | `M-L1-CH-ST-001`, лестница к полукруглому мостику круглого зала | [P-220, B1-076](https://loveread.ec/read_book.php?id=48197&p=76) |
| RT024-G, подвесная лестница к поднятой диспетчерской | `M-L1-AH-OLD-ST-001`, лестница высоко в ангаре B1-110 | [P-313, B1-110](https://loveread.ec/read_book.php?id=48197&p=110) |
| RT024-J, спуск из той же диспетчерской | **Та же физическая лестница RT024-G** внутри одного эпизода, не абстрактно все старые лестницы | [P-317, B1-113](https://loveread.ec/read_book.php?id=48197&p=113) |
| RT030-G, доступ к верхней операторской первого ангара катеров | `M-L1-FH-001-ST` | [P-365, B2-014](https://loveread.ec/read_book.php?id=53370&p=14) |

Отдельное источниковое различие: **первый исправный ангар двух катеров** (`M-L1-FH-001`) и **соседний ангар с тремя повреждёнными катерами** (`M-L1-FH-002`) — два разных физических ангара. Между их операторскими есть проход, но это не делает два ангара одним помещением. [P-367/368, B2-015](https://loveread.ec/read_book.php?id=53370&p=15).

Источники R03 и B1/B2 уже были проиндексированы ранее. R18 компилирует только обоснованные отношения **в одну общую задачу**, не подменяя исходные записи.

## 2. Шесть оставшихся неразрешённых пар

Для каждой ниже надо подтвердить **оба варианта** реальными решателями:
«одно физическое место» и «два разных». Никакой вариант не должен становиться фактом из первого SAT.

1. Лестница круглого зала RT015-J ↔ подвесная лестница старого ангара RT024-G.
2. Лестница из старой пультовой RT023-A ↔ остатки лестницы круглого зала RT015-J.
3. Лестница RT023-A ↔ подвесная лестница старого ангара RT024-G.
4. Исходный концептуальный `MOAG-G-0053` ↔ физический кандидат комплекса `M-L1-CG-001`: предварительное соответствие из индекса, **не утверждённое слияние**.
5. Старый грузовой комплекс `M-L1-CG-001` ↔ высокий старый ангар из эпизода B1-110 `M-L1-AH-OLD-001`.
6. Ангар со спящими изменившимися взрослыми `MOAG-G-0057` ↔ высокий старый ангар B1-110 `M-L1-AH-OLD-001`.

Все неизвестные остаются **в отдельной таблице R18** с пометкой, что слияние/разделение пока не доказано. Один и тот же обзор эпизода не является доказательством единой ангара.

## 3. Проверка реальными MiniZinc + Python OR-Tools

Применяется действующий интегрированный `integrated_spatial_r15.mzn`, а не новый собственный решатель. Четыре источниковых равенства и одно источниковое различие с provenance-URL передаются вместе со всеми ограничениями R11–R17.

```powershell
python tools/moag_topology/bootstrap_r11.py
python tools/moag_topology/identity_alternatives_r18.py --out moag-r18-run
python -m unittest discover -s tests -p test_moag_identity_r18.py -v
```

Ожидаемые реальные тесты:

- **SAT** на общей модели, CP-SAT witness перепроверяется MiniZinc при всех фиксированных переменных.
- **12 разрешённых альтернатив** (6 пар × совпадение/различие), каждая SAT обоими backend и перепроверена на фиксированном свидетеле.
- **UNSAT №1:** принудительно разделить RT024-G и RT024-J, хотя явно описан возврат по той же лестнице. Источниковое ядро содержит P-317 и синтетическую инверсию.
- **UNSAT №2:** принудительно объявить первый и соседний ангары катеров одним, несмотря на два разных источниково указанных ангара. Ядро содержит P-367/P-368 и синтетическое слияние.
- Абляция источникового семейства: искусственные требования должны стать SAT **без** соответствующего доказательного равенства/различия.
- Полный регрессионный CI на Windows/Linux. Исправлять обнаруженные тестами ошибки, не скрывать пропуски.

## 4. Что R18 не меняет

- **R09 — 593/845**, никаких новых комнат/удалений старых графовых узлов.
- Ранее установленная многоярусность, авторские схемы и все 52 маршрута с 378 стадиями.
- Ранее доказанные 25/378 маршрутных привязок к 12 условным объёмам; **353 не привязанных этапа сохранены**.
- Тождество лестниц не делает их частью одного этажа. Наличие прохода между операторскими не превращает их в одну комнату.
- **Изменений размеров и координат XYZ нет**, не объявляется единая архитектурная оболочка.
- `main`, исходные R09–R17, авторские иллюстрации и Archicad не изменяются; PR держать как draft.

**Следующий содержательный шаг:** на основании доказанных повторных посещений снимать ложные графовые тождества, затем привязывать реальные разные помещения к авторским планам, не теряя маршрутов и запретов на их произвольное сокращение. Для старых грузовых ангаров требуется дополнительное чтение B1-074/104/110 и других эпизодов, прежде чем утверждать физическое совпадение.
