## PR66/67 compatibility audit

The PR66 document catalog duplicates machine source identities for SP17 and
SP50, but not the machine atomic rule set. They are joined as document identity
links, preserving all 24 historical bindings and 12 PR67 checks. The other
three legacy documents are explicitly outside the scoped roof package.
No metadata record or PASS_DOCUMENTED reference edge is promoted to a
confirmed machine rule or engineering verdict.

The previous adapter lacked exact building type, module/depth routing,
quarantine release gates and canonical machine IDs. These are now explicit.
The existing machine resolver originally opens every block in its catalog;
the facade limits this to the requested dependency closure while reusing its
original resolve, dependency and guard methods. Only one rule file is read.

Status incompatibility is preserved: machine `confirmed` describes a stored
source claim; `STORED_FIELDS_PASS` describes validation by the original source
validator; APA `NOT_VERIFIED` describes project acceptance. `PASS_DOCUMENTED`
from PR67 is document-reference evidence only. None implies physical contact,
engineering suitability or audited_ready release.

SP17's existing passport tracks amendments1–5 and warns that changed Table4.1
rows require the exact amendment5 overlay. The generic slope procedure is not
a numeric lookup row. SP50.13330.2024 is mapped to its existing passport, not
globally substituted for every SP50 reference. The existing dependency policy
requires the exact dated/undated body occurrence; ambiguous references remain
unresolved. No global pinning or automatic edition upgrade is implemented.

## Working result and limits

The user confirmed IZHS for the current model. The cached four original
Wall/Roof junctions produce 36 bindings to nine existing SP17 rules. All retain
NOT_VERIFIED: the branch and blocks are quarantined/design_only, roof system
and layers are not source-bound, and the upstream roof calculators are declared
but not implemented. Existing nominal dimensions are not transferred into the
project. Roof.usable/roof.pitched_insulated functions and table-row branches
remain separately denied where exact inputs are missing.

The original 109-GUID evidence, five target body signatures, materials/stories,
and the previous gap measurements are reused without remeasurement. No new
Archicad calls, geometry checks, PLN saves/opens, APX changes or engineering
claims occur. Current live-model equality is not reasserted in this package.
Source snapshot hashes make CI reproducible without private-repository network
credentials. PR66/67 remain operational and unchanged.
