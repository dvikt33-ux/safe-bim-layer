# Нативное моделирование в Archicad 30

APA использует команды Tapir 2.0 через DynamicCommands и существующий SceneWriter. Привязка одной тестовой копии включает путь и SHA-256 PLN, исходный файл, версию и сборку Archicad, SHA-256 APX на диске, путь модуля загруженного процесса, встроенные идентификаторы APX и отметку запуска процесса. Подтверждение оператора относится к SHA-256 файла предконтроля с этими данными и точным проектным заданием.

## Лестница

`stage-stair` берёт марш из существующего BIM Graph проектного варианта. Для R07 `house-a` это 20 подступенков по 0,15 м, проступь 0,28 м, ширина 1,05 м, отметки 0 и +3 м. Обе площадки по 1,20 м относятся к проектной геометрии. Подготовка отдельной копии испытывает сам марш. В графе дома сохраняются связи с двумя перекрытиями и запроектированным проёмом.

Перед записью APA читает подлинные этажи и наличие указанного избранного типа Stair, сверяет размещение и регистрацию команд. Штатный `CreateStairs` создаёт один Stair. Глубина проступи определяется по расстояниям между последовательными верхними гранями на оси марша из `Get3DGeometryOfElements`. Отчёт отдельно сохраняет поле `treadDepth` нативной записи, которое Tapir документирует как ненадёжное для измерения построенных проступей. Сверяются число и высоты ступеней, габариты, начало и конец, отметки, GUID и нативная иерархия. Отдельное испытание марша оставляет сопряжение с плитами, высоту в свету и конструктивную приёмку открытыми.

Источники контракта и построения геометрии. [Tapir 2.0.0 CreateStairs](https://github.com/ENZYME-APD/tapir-archicad-automation/blob/2.0.0/archicad-addon/Examples/Element/CreateStairs.py) · [Graphisoft Archicad 30 API_StairType](https://graphisoft.github.io/archicad-api-devkit/struct_a_p_i___stair_type.html)

## Изменение сгруппированной стены

`stage-wall` использует зафиксированный кандидат с одним GUID стены, GUID её группы, исходной и новой высотой. Предконтроль сверяет размеры по свойствам и BREP, а также состав группы. SceneWriter записывает включение Suspend Groups, изменение и восстановление исходного режима отдельными операциями в одном SQLite-журнале. При прерванном соединении проверяется возможность восстановить режим в том же экземпляре. Если состояние модели остаётся неопределённым, сохраняются следы операции и дальнейшая запись блокируется.

## Нативная приёмка

Откройте в Archicad 30 точный файл из `job.json` подготовленного задания, начиная с лестницы. Убедитесь, что загружен согласованный APX, и перейдите в окно плана. `$Job` задаёт абсолютный путь к подготовленному заданию. Команды выполняются из распакованного комплекта APA тем же Python, который использует комплект.

```powershell
python -m apa ac30-native preflight --job $Job
```

Ожидается `READY_FOR_EXPLICIT_TEST_RUN` и `modelWrites=0`. Проверьте `preflight.json`, модель, режим группировки для стены и возвращённый `confirmSha256`. Следующая команда выполняется только по решению оператора по этому предконтролю.

```powershell
python -m apa ac30-native execute --job $Job --confirm-preflight $ApprovedSha256
```

После независимой проверки результата выполняется один `SaveProject`. `saved.json` и `guarded-save.snapshot` подтверждают сохранённые байты. `SAVED_PENDING_REAL_REOPEN` требует отдельного наблюдения закрытия и повторного открытия того же файла.

```powershell
# После штатного закрытия именно тестовой PLN
python -m apa ac30-native verify-closed --job $Job
# После открытия той же сохранённой PLN
python -m apa ac30-native verify-reopen --job $Job
```

`SAVE_REOPEN_VERIFIED` требует совпадения SHA-256 PLN, GUID, сигнатур BREP, привязок к этажам и повторной геометрической проверки. Сбой с `attempted.json` или журналом требует сверки `scene-v1-attempts.sqlite3`, `dispatch.jsonl` и `raw.jsonl` по фактической модели. В этом состоянии повтор команды записи заблокирован. Закрытие и открытие выполняет оператор штатными средствами.

## Проверка графа дома

```powershell
python -m apa plan --tapir2 --intent $Design --output $Plan
```

В `tapir2Preview` стены используют абсолютную Z Tapir 2. Отметки плит уже абсолютные. Сохраняются ссылки окон и дверей на стены и зависимости лестницы от плит. Контрактная компиляция R07 охватывает 22 операции. `stair-required` остаётся открытым до проверки лестницы в составе дома. Для выпуска документации применяются прежние нативные виды, Layout и Publisher после проверки сохранённой модели и связей листа. [Документация APA](APA_BIM_DOCUMENTATION.md)
